동물 12종 표정 교체용 SVG

- 캐릭터 파일은 각각 1000×1000, 투명 배경, 기존 눈 제거 상태입니다.
- 각 파일에 첨부 eyes.svg의 7개 눈 표정과 tears.svg의 눈물 벡터가 내장되어 외부 참조가 필요 없습니다.
- preview.html을 브라우저에서 열면 캐릭터/표정/눈물을 선택하고 현재 상태를 SVG로 저장할 수 있습니다. 인터넷 연결 불필요.
- SVG 직접 편집: #eyes의 visibility를 visible로 변경하고, #eyes-left와 #eyes-right의 href 및 xlink:href를 #asset-happy-left / #asset-happy-right 등으로 변경합니다. 표정: normal, happy, closed, squeeze, angry, wink, dizzy. 눈 없음은 #eyes의 visibility=hidden. #tears의 visibility=visible이면 눈물이 표시됩니다.
- eye_anchors.json: 1000×1000 좌표의 좌우 눈 중심과 각 눈의 시트 배율. 좌우는 화면 기준입니다.
- 각 캐릭터의 눈 중심과 기존 눈 높이를 기준으로 비율을 맞췄으며, 넓은 눈 표현끼리 겹치지 않도록 최대 배율을 제한했습니다.
- 고양이, 불독, 참새의 눈이 걸쳐 있던 얼굴색 경계는 새 눈을 자유롭게 바꿀 수 있도록 벡터 경계를 복원했습니다.
