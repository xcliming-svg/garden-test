# garden-test

Phaser 3.90.0 기반 **로그라이크 게임용 화면/씬 스켈레톤**. 게임플레이는 포함하지 않습니다.

## 웹 실행

1. 인터넷에 연결된 환경에서 이 프로젝트의 `index.html`을 웹 브라우저로 엽니다. 정적 웹 호스팅에 동일 파일을 올려도 됩니다.
2. 메인 메뉴에서 **새 게임**을 눌러 10×10 정원 그리드, 상단 HUD, 도안, 하단 슬롯 및 크기 비교용 정적 도형이 있는 전장 시안에 들어갑니다. 도안 제목을 클릭하면 접거나 펼칠 수 있습니다.
3. 게임 화면에서 **ESC**로 일시정지 메뉴를 열고, 계속하기·설정·도감·메인 메뉴 복귀를 확인할 수 있습니다.
4. 결과 씬을 게임플레이 없이 직접 보려면 `index.html?preview=1`로 엽니다. 이때에만 메인 메뉴에서 성공/실패 화면으로 이동하는 개발용 버튼이 표시됩니다.

현재 Phaser 라이브러리는 **고정 버전 CDN**에서 불러옵니다. 따라서 최초 실행 및 CDN 캐시가 없는 환경에서는 인터넷이 필요합니다. **오프라인 실행 패키지나 Steam 업로드용 실행 파일은 아직 생성하지 않았습니다.** 이는 이번 씬 작업 범위 밖입니다.

## 등록된 Phaser 씬

| 씬 | 구성 | 진입 |
| --- | --- | --- |
| `Boot` | 시작 진입점 | 페이지 열기 |
| `MainMenu` | 새 게임 / 이어하기(비활성) / 설정 / 도감 / 종료(웹에서 비활성), 안내 패널·크레딧 없음 | Boot, 게임 복귀, 결과 |
| `Game` | 640×360 논리 화면 / 상단 HUD / 10×10 정원 / 접이식 도안 / 정적 에셋 크기 도형 / 하단 슬롯 | 새 게임 |
| `Pause` | ESC 일시정지 / 계속 / 재시작(비활성) / 설정 / 도감 / 메인 메뉴 | 게임에서 ESC |
| `Settings` | 일반·사운드·화면 탭(적용/저장 안 됨) | 메뉴, 일시정지 |
| `Codex` | 향후 맵 도감이 들어갈 빈 화면. 도감 데이터·기능 없음 | 메뉴, 일시정지 |
| `Confirm` | 게임에서 메인 메뉴 복귀 확인 | 일시정지 |
| `Victory` | 성공 결과 / 비어 있는 통계 자리 / 새 게임 / 메인 메뉴 | 개발용 미리보기 |
| `Defeat` | 실패 결과 / 비어 있는 통계 자리 / 새 게임 / 메인 메뉴 | 개발용 미리보기 |

**구현하지 않은 것:** 이동, 적, 공격, 전투, 아이템, 맵 생성, 보상, 승패 판정, 런 진행도, 저장/로드, 설정값 적용/저장, 통계 계산, 오디오, Steam SDK 연동, 데스크톱 패키징.

## 전장 시안 및 에셋 인수인계

- 논리 좌표: 640×360 (16:9). 실제 렌더링 버퍼를 창에 들어가는 최대 16:9 크기로 맞춥니다. 비정수 배율도 허용하며, 글자는 현재 배율에 맞춰 고해상도 텍스처로 렌더링합니다.
- 정원 16px × 10칸, 도안 8px × 10칸, 장착 슬롯 24px. 보석 요구량 999는 최대 세 자리 표시를 확인하기 위한 UI 예시입니다. 실제 비용을 정한 것은 아니며, 아이콘과 숫자는 한 행으로 중앙 정렬됩니다.
- 수호자·적·보석·회복약·네모 아이템은 크기 비교용 정적 도형입니다. 실제 에셋, 이동, 스폰, 충돌, 획득, 장착, 확장 로직은 없습니다.
- [ASSET_SPECS.md](./ASSET_SPECS.md): 에셋별 목표 PNG 크기, 색상 식별표, 경로 제안, 원본 SVG 보존 정책 및 배치 수치.
- [src/game-layout.js](./src/game-layout.js): 규격과 정적 화면 렌더링의 기준 파일.

## 출처와 의사결정

기술 선택과 화면 구성의 근거, 추후 작업 금지 범위 및 개발 규칙은 [AGENTS.md](./AGENTS.md)에 정리했습니다. 씬 참조 문서는 [Phaser 공식 Scene 가이드](https://docs.phaser.io/phaser/concepts/scenes)입니다.

이 작업에서는 요청에 따라 자동 테스트, 실행 테스트, 빌드 테스트를 수행하지 않았습니다.
