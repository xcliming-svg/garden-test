# garden-test

> **960×540 비교 브랜치:** 이 문서의 기존 640×360 수치와 확정 이력은 main 기준으로 보존한다. 현재 브랜치의 실험 규격 및 예외는 [960×540 비교 문서](./docs/resolution-960x540.md)를 우선 참조한다. main 규격 변경 승인 또는 게임플레이 구현을 뜻하지 않는다.


Phaser 3.90.0 기반 **로그라이크 게임용 화면/씬 스켈레톤**. 게임플레이는 포함하지 않습니다.

## 웹 실행

1. 인터넷에 연결된 환경에서 이 프로젝트의 `index.html`을 웹 브라우저로 엽니다. 정적 웹 호스팅에 동일 파일을 올려도 됩니다.
2. 메인 메뉴의 **새 게임**에서 10×10 정원, 상단 HUD, 접을 수 있는 도안, 하단 9+1 슬롯, 드롭 카드 및 능력치 미리보기를 확인합니다. 현행 `devel`의 정원 노드 외형 24px, 장착 슬롯 36px, 드롭/꽃/아이템 16px 원본 이미지와 참조 색상·정보창 규격은 [960×540 문서](./docs/resolution-960x540.md)를 따릅니다. 드롭을 올리거나 클릭해 정보창을 확인하고 일반 슬롯에 드래그해 임시 장착·교체할 수 있습니다. 꽃은 인접 후보에 배치합니다. 확장 비용 999는 표시 전용입니다. 모두 화면 검토용이며 실제 게임플레이를 구현하지 않습니다.
3. 게임 화면에서 **ESC**로 일시정지 메뉴를 열고, 계속하기·설정·도감·메인 메뉴 복귀를 확인할 수 있습니다.
4. 결과 씬을 게임플레이 없이 직접 보려면 `index.html?preview=1`로 엽니다. 이때에만 메인 메뉴에서 성공/실패 화면으로 이동하는 개발용 버튼이 표시됩니다.

devel URL 비교 실험(미확정): `?type=1` 짙은 갈색, `?type=2` 적갈색, `?type=3` 청록색 정원. 각 모드에서는 도안 내부 교차점도 비운다. 파라미터 없는 화면은 기존과 동일하다. 자세한 내용은 [현행 규격](./docs/resolution-960x540.md)을 참조한다.

현재 Phaser 라이브러리는 **고정 버전 CDN**에서 불러옵니다. 따라서 최초 실행 및 CDN 캐시가 없는 환경에서는 인터넷이 필요합니다. **오프라인 실행 패키지나 Steam 업로드용 실행 파일은 아직 생성하지 않았습니다.** 이는 이번 씬 작업 범위 밖입니다.

## 등록된 Phaser 씬

| 씬 | 구성 | 진입 |
| --- | --- | --- |
| `Boot` | 시작 진입점 | 페이지 열기 |
| `MainMenu` | 새 게임 / 이어하기(비활성) / 설정 / 도감 / 종료(웹에서 비활성), 안내 패널·크레딧 없음 | Boot, 게임 복귀, 결과 |
| `Game` | 640×360 논리 화면 / 상단 HUD / 10×10 정원 / 접이식 도안 / 정적 에셋 크기 도형 / 하단 슬롯 | 새 게임 |
| `Pause` | ESC 일시정지 / 계속 / 재시작(비활성) / 설정 / 도감 / 메인 메뉴 | 게임에서 ESC |
| `Settings` | 일반·사운드·화면 탭(적용/저장 안 됨) | 메뉴, 일시정지 |
| `Codex` | 향후 맵 도감이 들어갈 빈 화면. 도감 데이터·기능 없음 | 메뉴, 일시정지 |
| `Confirm` | 게임에서 메인 메뉴 복귀 확인 | 일시정지 |
| `Victory` | 성공 결과 / 비어 있는 통계 자리 / 새 게임 / 메인 메뉴 | 개발용 미리보기 |
| `Defeat` | 실패 결과 / 비어 있는 통계 자리 / 새 게임 / 메인 메뉴 | 개발용 미리보기 |

**구현하지 않은 것:** 이동, 적, 공격, 전투, 아이템, 맵 생성, 보상, 승패 판정, 런 진행도, 저장/로드, 설정값 적용/저장, 통계 계산, 오디오, Steam SDK 연동, 데스크톱 패키징.

## 전장 시안 및 에셋 인수인계

- 논리 좌표: 640×360 (16:9). 실제 렌더링 버퍼를 창에 들어가는 최대 16:9 크기로 맞춥니다. 비정수 배율도 허용하며, 글자는 실제 배율(최소 1)에 맞춰 래스터화합니다. 글자는 고해상도 NEAREST(sharp)로 통일하며 원본 글리프 픽셀을 직접 보정하지 않습니다. 비교용 URL 옵션은 제거했습니다.
- 상단 HUD 24px, 하단 36px, 전장 640×300. 한 줄 시간(00:00:00) / 처치 수 / 보석 / 정원 완성도(30% 정적 시안) 순서로 배치합니다. 앞 세 열의 폭은 최소 144px로 동일하고, 수치는 레이블/아이콘 바로 뒤에 표시하며 정원 완성도는 남은 폭을 사용하며 게이지 내부 높이 8px, 전체 높이 10px입니다. `index.html?hud=stress`에서 시 4자리 및 처치·보석 12자리 표시를 확인할 수 있습니다. 게임 수치 상한을 정한 것은 아닙니다.
- 정원 16px 면 + 1px 공백, 17px 간격 × 10칸, 도안 내부 8px + 공통 1px 선, 10×10(외곽 포함 91×91), 장착 슬롯 24px, 좌우 간격 2px. 보석 요구량 999는 최대 세 자리 표시를 확인하기 위한 UI 예시입니다. 실제 비용을 정한 것은 아니며, 아이콘과 숫자는 한 행으로 중앙 정렬됩니다.
- 하단 좌측 방어력·최대 체력·행운, 중앙 일반 9칸+비활성 확장 1칸, 우측 이동 속도·획득 범위·초당 피해량. 좌우는 바깥 8px부터 42px씩 3열로 배치하며, 7px 레이블과 수치 묶음을 중앙 정렬하며 행 간격은 1px입니다. 드래그 대상 슬롯에서 교체 후 수치와 증감을 한 행에 미리 표시합니다. 능력치/효과는 임시 예시이며 실제 게임 수치나 확률 계산은 아닙니다.
- UI 글꼴: Fusion Pixel 10px Proportional KO Regular(영문·한글·숫자 공통). [폰트 출처·OFL 전문](assets/fonts/README.md)을 함께 배포합니다. 글꼴은 로컬 CSS에 내장되어 별도 설치·폰트 CDN이 필요하지 않습니다.
- 화면 테스트 전용: 중앙 2×2 꽃 4종, 모든 적은 달팽이, 모든 카드와 장착 아이콘은 손수레입니다. 수호자는 확장 후보 바깥 한 칸에서 사각형 순찰하는 테스트 도형이며, 보석은 기존 정적 도형입니다. 꽃·손수레는 제공 SVG/이미지 시트에서 목표 크기로 직접 픽셀 변환한 알파 0/255 임시 샘플이며, 달팽이는 기존 근사 샘플입니다. 최종 에셋이 아닙니다. 꽃 및 아이템 임시 배치 상태는 새 게임에서 초기화됩니다. 실제 게임 이동·스폰·충돌·획득·장착·확장 로직은 없습니다. 순찰은 UI 확인용 애니메이션입니다.
- Garden 32 팔레트: `src/palette.js`의 고유 32색으로 UI 및 임시 도형을 통일합니다. 전장·HUD 동일 배경, 최소 경계선, 단색 사각형 슬롯, 황록색 완성도 게이지를 적용합니다.
- [ASSET_SPECS.md](./ASSET_SPECS.md): 에셋별 목표 PNG 크기, 색상 식별표, 경로 제안, 원본 SVG 보존 정책 및 배치 수치.
- [src/game-layout.js](./src/game-layout.js): 규격과 정적 화면 렌더링의 기준 파일.

## 출처와 의사결정

기술 선택과 화면 구성의 근거, 추후 작업 금지 범위 및 개발 규칙은 [AGENTS.md](./AGENTS.md)에 정리했습니다. 씬 참조 문서는 [Phaser 공식 Scene 가이드](https://docs.phaser.io/phaser/concepts/scenes)입니다.

초기 씬 작업에서는 요청에 따라 테스트를 하지 않았습니다. 이후 UI 개선은 JS 구문 및 모의 동작 테스트를 수행했습니다. 실제 브라우저 자동 실행과 빌드 테스트는 미실행입니다. 상세 검증 상태는 확정 기록 및 변경 이력을 참조합니다.

### 확정 상태색 및 순찰 테스트

하단은 테두리 없는 단색 사각형을 유지하며 드래그 중 황록 +와 선택 사각형을 추가합니다. 중앙 정원은 연결된 어두운 흙밭 위에 꽃을 표시하며 평상시에도 인접 후보가 나타납니다. 수호자는 후보 바깥 한 칸의 사각형을 순찰합니다. 실제 게임 이동이 아닌 화면 테스트입니다.

### 흙밭 시안

기본 주소에서 확인합니다. 심어진 흙밭과 확장 후보는 bark(#7C4C24) 30%로 동일하며, 드래그 중에는 각 후보에 황록 +를 표시하고 진입한 유효 대상만 같은 색의 1px 사각형으로 바꿉니다. 대상에서 이탈하면 +로 복귀합니다. 이전 `?slot=flat` 옵션은 제거했습니다.

- 글꼴은 기존 고해상도 NEAREST 방식으로 확정합니다. 글자 가장자리 이진 알파 비교 모드는 사용자 비교 후 제거했습니다.

- 카드 패딩 비교 전용: `card-compare.html`. 실제 16×16 임시 아이콘, 1px 외곽선, 패딩 1/2/3/4px(외형 20/22/24/26px) 비교. 1~4배 확대 및 Canvas 2D 외곽선 채움 방식별 브라우저 시간 측정. 사용자 선택에 따라 패딩 3px(외형 24px)을 확정하며 비교 페이지는 테스트용으로 유지.

- 정원 흙 면 크기 비교 전용: `index.html?garden=24` (24×24 흙 면, 1px 공백, 25px 간격, 250×250 논리 영역). 꽃 16px, 꽃 카드 24px, 아이템 카드 24px, 기존 드래그 방식 유지. 기본 주소는 16px 흙 면 그대로.
