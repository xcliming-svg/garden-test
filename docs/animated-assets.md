# 애니메이션 SVG 에셋 적용 (2026-11-13)

- 범위: main c811115에서 분기한 feature/animated-svg-assets의 화면 검토용 실험. 실제 게임 전투, 이동 AI, 충돌, 획득 및 성장 시스템은 구현하지 않는다.
- 사용자 제공 snail__feelers__003.zip의 SVG 102개를 assets/animation/에 원래 이름과 내용으로 보존한다. 동일한 로컬 원본과 첨부 ZIP의 정규화 텍스트 해시(FNV-1a 32bit 1ab44bc2)를 대조했다.
- 활성 15종 × 4프레임(000~003) = 60장. 꽃은 bloom, 수호자는 walk를 사용한다. sprout, stem, walk_soft_arms와 grasshopper/rabbit의 004는 보존만 하며 이 시안에서 재생하지 않는다.
- 원본 1000×1000 SVG를 Phaser SVG 로더로 250×250에 래스터화한다. 종별 전체 프레임의 알파 외곽을 포함하는 고정 정사각형 크롭을 사용해 프레임별 확대/축소, 비율 왜곡 및 중앙점 이동을 막는다. 꽃은 공통 크롭. 원본 색을 유지하며 SVG 텍스처에 LINEAR 필터를 적용한다. Garden 16 UI 및 기존 손수레/보석 색과 저해상도 테스트 원본은 그대로 유지한다. SVG 원본 색은 이번 에셋 미리보기의 명시적 예외다.
- 논리 좌표계 960×540, 아래 크기는 정사각형 표시 영역의 한 변(투명 여백 포함)이다. 실제 아트의 종횡비는 원본을 유지한다.

- 중심 2×2 정원(44,45,54,55)에 꽃 종류별 한 개, 기존 꽃 드롭 3개 및 드래그 고스트/심은 꽃도 동일한 16px 애니메이션을 사용한다. 카드 외형 24px, 입력·후보·배치 규칙 변경 없음.
- 수호자 두 명은 동일한 순찰 경로의 반 바퀴 간격에서 시작, 기존 72 논리 px/s 이동과 정원 확장 시 새 경로 합류를 독립 수행한다. 애니메이션은 걷기 4프레임 반복. 좌우 이동에 따라 반전한다.
- 동물 62개는 기존 달팽이 배치 앵커를 사용하고 9종을 균등 순환 후 섞는다. 종별 최소 1개 노출 보장. 앵커에 ±3px 후보 위치를 사용하되 기존 드롭 및 이전 배치와 지나치게 가까워지지 않도록 제한한다. 동물 자체는 좌표 이동 없이 애니메이션만 반복한다. 위치/수량/크기는 테스트용이며 충돌 판정이나 최종 밸런스 수치가 아니다.
- Boot에서 활성 SVG를 사전 로드하고 애니메이션을 1회 등록한다. 씬 재진입 시 텍스처를 재사용한다. Pause 시 씬의 애니메이션과 이동이 함께 중단된다.
- 코드: src/animated-assets.js(파일/크롭/크기/FPS/재생), src/scenes.js(Boot), src/game-layout.js(배치/순찰), src/test-sprites.js(기존 카드와 SVG 꽃 연결).
- 실행: SVG를 HTTP로 로드하므로 프로젝트 폴더에서 정적 웹 서버(예: python -m http.server 8000)를 실행하고 http://localhost:8000/ 로 접속한다. CDN 인터넷 연결은 여전히 필요하다. file:// 직접 열기는 브라우저 로컬 XHR 정책으로 지원하지 않는다.
- 검증: tests/reference-ui.mjs에 SVG 실제 로드/크롭/프레임 변화/9종 노출/2인 순찰/정지/일시정지 검사를 추가하고 기존 UI 검사를 유지한다. 실행 결과: [실제 Chromium 회귀 961/961 통과](https://github.com/xcliming-svg/garden-test/actions/runs/43424399319) (코드 20cd7ad, 2026-11-13). 5개 해상도, 5개 언어, DPR2, 기존 UI/드래그/일시정지, 신규 SVG 60프레임 로드·크롭·실제 반복·2인 순찰·동물 정지 및 9종 노출을 검사했다. 별도 Chromium 픽셀 검사에서도 15종 60장 모두 서로 다른 4프레임 및 크롭 밖 알파 0을 확인했다. 최대 24px 정사각형을 가정한 1,000회 배치 시뮬레이션에서 동물 간 겹침 0회. 다른 브라우저·OS와 실제 전투 밸런스는 미검증.
