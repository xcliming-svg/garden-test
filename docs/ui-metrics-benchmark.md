# UI 크기·간격 비교 평가 (2026-11-12)

## 범위 및 기준

- 이전 devel A안에서 화면 비율 960×540, 꽃밭·슬롯 내부 24px, 외부 1px 프레임(전체 26px), 꽃/아이템 원본 16px, 카드 내부 패딩 4px, 팔레트·색상·아트·기존 동작을 고정하고 UI의 크기·글꼴·간격만 변경했다.
- 참고는 [960×540 문서의 유사 게임 화면](./resolution-960x540.md#유사-게임-화면-참고-2026-11-12)의 Boneraiser Minions, Tiny Rogues, 20 Minutes Till Dawn. 실제 게임 소스의 UI 상수나 공식 가독성 점수를 확인했다는 뜻은 아니다.
- A~F 1차 실행에서 드래그 중 정상적으로 HUD 위에 있는 카드까지 전장 밖 오류로 처리한 검사기 오탐을 발견했다. 드래그 중인 카드만 해당 검사에서 제외하고, 정확한 스냅 위치/알파/고스트 상태 검사를 추가했다. D의 가독성 개선을 더 조밀하게 배치하는 G~J를 추가한 후 A~J 모두 같은 수정된 검사로 재실행했다. 기존 게임 동작을 우회하거나 오류를 숨기지 않았다.
- [비교 실행 소스](https://github.com/xcliming-svg/garden-test/tree/feature/ui-metrics-benchmark), [최종 실행 및 report.json·실제 화면 PNG](https://github.com/xcliming-svg/garden-test/actions/runs/43215418688), [1차 실행](https://github.com/xcliming-svg/garden-test/actions/runs/43215125260). Chromium + Phaser 3.90.0 + 번들 Fusion Pixel 폰트 실제 실행, 640×360/960×540/1280×720/1920×1080. 기본 고정 규격에서 12자리 HUD 스트레스, 모든 9개 씬, 장착·교체·잠김 거부·정원 배치·도안, 텍스트 및 경계·겹침, 리사이즈 및 런타임 오류를 검사했다.

## 점수 산식 (100점, 자체 휴리스틱)

- 가독성 40: 실제 Canvas 글리프 높이를 1280×720에 환산, 7px에서 0, 16px에서 만점으로 선형 클램프. 레이블/수치/시간/능력치 레이블/능력치 수치/정보창/메뉴 가중치 15/15/10/15/15/20/10%.
- 공간 25: 도안 외곽 제외 전장 면적 비율(75%, 68~86% 정규화) 및 가장 큰 정보창 면적 비율(25%, 22~4% 역정규화).
- 간격 20: 슬롯 간격 3~6px, 버튼 최소 세로 패딩 5~12px, 정보창 패딩 8~12px·행 간격 3~6px, 하단 슬롯 세로 여백 6~14px, 능력치와 슬롯 분리 20~100px를 권장 범위로 설정. 가중치 20/20/20/15/15/10%. 범위 밖 비례 감점.
- 위계 10: 시간/레이블 실측 글리프 높이 비율 1.5~2.5 및 메뉴/정보창 1.3~2.2, 가중치 55/45%.
- 배율 5: 네 해상도에서 선택된 경계 좌표와 크기가 정수 물리 픽셀에 대응하는 비율. 모든 래스터가 픽셀 퍼펙트하다는 의미는 아니다.
- 필수 검사 하나라도 실패 시 순위 제외. 이 점수는 가중치와 목표값을 지정한 자체 기준이며 실제 사람 대상 선호도·가독성 조사나 장르 공식 표준이 아니다. 소수점은 계산 결과 표시용.
