# 기본 플레이 — 전장 깊이와 저속 도입부

2026-11-19 · Phaser 3.90.0 · 기본 index.html만 적용. lab.html은 기존 비교 동작 보존.

## 적 도입부

> 아래는 저속 도입부 및 하트 수정 당시 기록. 후속 시간대별 웨이브와 아이템 성장의 현행 기준은 [성장·웨이브 적용 규격](./survivor-progression.md).
- 0~180초: 애벌레만, 첫 적 즉시, 이후 3초 이상의 출현 간격(기존 12초). 동시 상한 최초 3, 30초마다 +1(최대 65). 적을 처치해도 다음 출현 가능 시각 전에는 보충하지 않는다. 처치가 없더라도 0/3/6초에 순차 진입한다.
- 3분 풍뎅이, 5분 메뚜기, 7분 공벌레, 9분 나비, 11분 개구리, 13분 고양이, 15분 참새, 17분 생쥐, 19분 토끼, 21분 강아지, 23분 비둘기. 해금된 종을 레벨별 기존 가중치 6/3/1로 선택하고 미등장 해금 종을 우선한다.
- 출현 최소 간격: 0/3/5/9/15/23분부터 3/2.5/2/1.5/1.2/1초. 상한은 동시 생존 수이며 강제 충원 없음. 수치는 임시 플레이 밸런스.
- 요정 40px/s (최대 80), 적 종별 기존 기본/최대 속도는 [이동 속도](./movement-speed.md) 참조. 모든 적 rank 0, 최초 애벌레 20px/s(최대 30). 적의 공격 모션 시간·무기 밸런스는 변경하지 않는다. 자동 속도 상승은 적용하지 않으며 요정은 신발로 강화.
- 12종 모두 처음부터 출현하도록 했던 비교용 무작위 순열은 실제 플레이에서 사용하지 않는다.

## 전장 렌더링 순서
실제 Phaser depth, 작은 값부터 뒤→앞. HUD와 전장 레이어를 분리하고 카드와 보석을 투사체보다 앞에 배치한다. 컨테이너 자식은 내부 순서(테두리/면/아이콘/레벨 문자)를 유지.

| 깊이 | 요소 |
| --- | --- |
| -2 / -1.8 / -1 | 전장 바탕 / 잔디 패턴 / 정원 흙·후보 그리드 |
| 0.75 / 0.8~0.82 | 적 그림자 / 지면 효과·끈끈이·물풍선 착지 |
| 1~1.27 / 1.8 | 꽃(행 위치 기준) / 설치형 스프링클러·빗자루 |
| 3~3.99 | 적(발 위치 기준 Y 정렬) |
| 4~4.98 | 요정(Y 정렬), 외곽선 몸체 -0.001, 눈물 +0.01 |

| 7 / 8 | 보석·하트 / 꽃·아이템 카드 |
| 10 / 11 / 12 / 13 | 도안 바탕 / 꽃 아이콘·헤더 / 제목·화살표 / 입력 영역 |
| 15 | 꽃 배치 고스트 |

도안 꽃 아이콘은 셀 내부 8×8로 제한. 적/무기 필드 마스크는 유지. 레거시 비교 전용 객체는 기존 깊이 유지.

## 카드 생성
정원 전체 10×10 영역을 금지 구역으로 사용. 카드 외곽 24/32px 및 최대 부유 4px까지 반영하고 정원 및 도안에서 5px 여유 확보. HUD는 침범하지 않는다. 우선 다른 카드와도 겹치지 않는 가장 가까운 위치를 선택하고, 빈 공간이 없으면 카드 간 겹침만 허용한다. 사용자가 직접 드래그할 때는 정원에 들어갈 수 있다. 보석/하트는 기존 획득 방식 유지.

## 결과 팝업
승리/실패 시 Game 씬 pause, 결과 씬 launch 및 최상단 배치. 전장의 시간·적·요정·꽃·카드·투사체 상태 그대로 보존. 별도 결과 배경·상하단·런 결과·저장 안내 없음. 중앙 패널과 결과 수치, 새 게임/메인 메뉴 버튼만 표시. 이전 Game은 버튼 선택 시 종료. 실제 결과 화면에 배경 어둡게 덮는 오버레이도 없음.
