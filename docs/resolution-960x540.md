# 960×540 · 24px 그리드 / 16px 이미지 UI 비교 브랜치

- 브랜치: `feature/resolution-960x540`, 기준 main `7198cba` (2026-11-12).
- 상태: 사용자 요청에 따른 비교 실험. main의 확정 640×360 규격을 대체하거나 승인한 것이 아니다.
- 목적: 24px 타일을 기준으로 메뉴와 전장의 UI를 재설계한다. 사용자 정정에 따라 정원과 하단 슬롯은 내부 24px + 외부 1px 프레임, 꽃/아이템은 16px 원본을 사용한다. 초기 단순 1.5배 확대안(`9f50ba5`)을 대체하며, 실제 게임 기능 및 최종 아트 추가는 범위 밖이다.

공통 좌표와 타일/간격/폰트 토큰은 `GardenUI`에서 정의하고 `GardenGameLayout`에서 참조한다. 기능적 선은 1px 유지. 정원은 24px 흙 내부 면의 네 변 외부에 각각 1px edge 프레임을 그려 26px 피치로 배치한다. 인접 칸의 독립 프레임이 맞닿으므로 흙 면 사이 2px이며 추가 공백은 없다. 기존 점유·인접 후보만 표시, 나머지 투명. 흙 면 bark 30% 알파, 외곽선 불투명. 선택 외곽선은 기존 프레임에 일치한다. 하단 슬롯은 내부 24px grid(비활성 soil), 외부 1px slot(비활성 edge). HUD는 높이 32px, 1×16px 구분선, 상하 8px 여백. HUD 레이블과 수치는 서로 다른 글꼴 크기로 실측해 예약 폭을 계산한다. 하단은 좌우 각각 216px(72px×3열), 바깥 여백 12px, 슬롯과 각각 104px 간격이다. 슬롯은 높이 48px 하단 내에서 상하 11px 여백을 가진다. 꽃·아이템 드롭 카드 및 장착 카드도 외형 26px, 내부 24px, 아이콘 16px, 내부 패딩 4px, 외부 프레임 1px를 공유한다. 9+1 구성 및 비용 999는 기존 UI 테스트용이며 실제 초기 4칸 설계는 변경하지 않는다. 정보창은 192px 폭, 내부 168px, 4px 행 간격 및 2px 줄바꿈 간격. 외곽 위치는 x=12~948, y=44~484 안으로 보정한다. 기존 색상·드래그·스냅·교체·정원/순찰 기능은 유지한다.

## 메뉴 및 팝업

모든 씬을 960×540 좌표로 통일한다. 기본 버튼 288×32px(메인·일시정지), 세로 간격 8px, 기본 글꼴 12px, 작은 표시 10px, 팝업 제목 20px, 메인 제목 40px. 메뉴 보더/구분선은 논리 1px 유지, 호버 두께 불변. 기존 Garden 32 역할 및 오버레이 투명도 유지.

## 렌더링 및 아트 한계

- 실제 캔버스는 창에 들어가는 최대 16:9 크기, 모든 씬의 카메라는 960×540 논리 좌표에 매핑한다. 1920×1080에서 배율 2, 1280×720에서 4/3.
- 기존 Fusion Pixel 10px Proportional KO Regular 원본, 실제 카메라 배율(최소 1) 래스터화, NEAREST 유지. 12px 기본 글자는 10px 원본의 비네이티브 크기이며 실제 가독성은 미검증.
- 기존 꽃/손수레 16px 원본은 논리 16px로 표시하고 달팽이 12px 원본은 기존 18px 논리 표시를 유지한다. 새로운 고해상도 원본을 생성하지 않았다. FHD에서 꽃/손수레 원본 1px은 2×2 물리 픽셀, 전체 이미지는 32×32 물리 픽셀(main의 48×48보다 작음)이다.
- 기존 URL `?preview=1`, `?hud=stress` 유지. `?garden=24`는 기본 24px 흙 면과 동일하며, 기존 대형 비교는 `?garden=36`으로 명시한다(380×380 영역). 대형 비교에서 최대 점유 가정 시 순찰과 HUD 중첩 가능성은 기존 제약이다.
- `card-compare.html`은 main의 16px 아이콘 원본 및 기존 패딩 비교를 그대로 유지하는 별도 비교 도구이다.

- 기본, HUD 스트레스, 정원 24, 정원 36 모드 각각 28개 모의 검사(합계 112개) 통과: 좌표 및 24/26/16 크기, 정원 테두리·흙 면·텍스처 경계, 카드/슬롯 프레임, 확장 비용, 꽃 원본 및 중심, 스냅 외곽선, 배치, 장착/교체/잠김 거부, 취소, 순찰, 리사이즈 및 리스너 해제.

- 실제 브라우저 렌더링, 실제 폰트 실측, 픽셀 가독성, GPU 성능 및 사용자 선호도는 미검증. 게임플레이·저장·해금·실제 데이터 등 기존 미구현 범위는 유지한다.
