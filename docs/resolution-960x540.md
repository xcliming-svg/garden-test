## 상단 HUD 다국어 폭 예약

기본 한국어, HUD 전용 미리보기 `?lang=ko/en/ja/es/zh`(지역 접미어 허용). 게임 전체 번역, 실제 언어 설정/저장, 언어별 숫자 포맷 변경은 구현하지 않는다. 기존 12px 글꼴 크기, 32px HUD, 좌우 7.5px 패딩, 후속 요소 간격 5px, 최대 시간 네 자리 시와 처치/보석 12자리 숫자 예약 유지. 5개 언어의 실측 최대 시간/처치 레이블 및 숫자 예약 폭을 고려해 동일한 세 열 폭을 결정한다. 완성도 그룹도 가장 긴 레이블 폭을 예약한다. 완성도 그룹 앞의 구분선은 제거하고 독립 우정렬한다. 게이지 오른쪽 끝 x=952.5 고정(시간 그룹 시작 x=7.5와 동일한 7.5px 외측 패딩), 레이블은 게이지 시작 x=794.5의 왼쪽에서 정확히 5px 간격으로 배치하므로 짧은 번역에서도 간격이 벌어지지 않는다. 게이지 채움만 기존 UI 초록색 #6ABA2C를 적용한다. 기존 패딩 10px 버전에서는 실제 Chromium 5개 언어×3개 해상도(960×540, 1600×900, 1920×1080) 모두 동일 폭 167px, 게이지 x=792, 레이블 간격 5px 확인. 최신 패딩 버전의 검증은 변경 이력 참조. 번역 문자열의 모든 글리프가 기존 WOFF2 cmap에 있는지 fontkit으로 검증했다. 기존 회귀 포함 204/204 통과. ## 렌더링 및 한계

- 최대 16:9 창 맞춤, 960×540 논리 좌표 유지. 1920×1080은 2배, 1600×900은 5/3배. 실제 CSS 픽셀과 물리 픽셀은 브라우저/운영체제 배율에 따라 달라진다.
- 기존 Fusion Pixel 10px Proportional KO Regular 및 NEAREST 유지. 참조 게임의 실제 폰트 파일이나 내부 UI 수치는 확인하지 않았으며, 화면과 1:1 동일함을 보장하지 않는다. 1px 테두리·그림자는 FHD에서 2px로 표시된다.
- `?preview=1`, `?hud=stress`, `?garden=24`(기본 24px 외형), `?garden=32` 및 `?garden=36`(내부 32px 비교 호환) 유지. `card-compare.html`의 독립 패딩 비교 내용은 유지하며 색만 참조 팔레트에 맞춘다.
- 실제 Chromium 회귀검증 스크립트 `tests/reference-ui.mjs`는 `feature/reference-ui`에서 실행한다. 640×360/960×540/1280×720/1600×900/1920×1080, HUD 스트레스, UI 배치/색, 드롭·장착·꽃·팝업·화면 전환을 확인한다. 실제 Chromium 131/131 검사 통과([실행 및 스크린샷 아티팩트](https://github.com/xcliming-svg/garden-test/actions/runs/43318950238)), JS 7개 구문 검사 통과. 사람 대상 시각적 선호 평가 및 다른 브라우저는 미실시.

## 이전 버전의 검증 이력 (현행 참조 화면안과 구분)

- [10개 UI 후보 실제 Chromium 비교 평가](./ui-metrics-benchmark.md): 후보별 107개 검사(총 1070개) 통과. 점수 1위 J안(94.25점)을 당시 `devel`에 동일하게 적용했다. 640×360, 960×540, 1280×720, 1920×1080에서 글꼴과 UI 경계, 기존 화면 전환, 장착·교체·꽃 배치·잠김 거부 등을 검사했다.
- 실제 게임 화면 캡처 및 점수 원본은 [최종 GitHub Actions 실행](https://github.com/xcliming-svg/garden-test/actions/runs/43215418688) 아티팩트 참조. 실제 사람의 선호도, GPU 성능, 다른 브라우저 및 OS에서의 검증은 미실행.
- 게임플레이·저장·해금·실제 데이터 등 기존 미구현 범위는 유지한다.
