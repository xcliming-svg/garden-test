정원은 참조 트리 노드 외형 24px(내부 22px)를 유지하되, 인접한 셀의 테두리를 한 줄로 공유한다. 면·가로선·세로선·교차점은 각각 한 번만 그리며, 점유 및 상하좌우 후보만 표시한다. 배치 피치 23px와 외곽 포함 최대 231px에 꽃 중심·드래그 판정·고스트·순찰 좌표를 일치시킨다. 공유선 판정은 오른쪽/아래 셀, 마지막 외곽선은 마지막 셀에 귀속한다. 꽃과 아이템 원본은 16px 유지. 슬롯은 사용자 확정 규격 32px 정사각형으로 변경하고, 기존 9+1 미리보기와 장착·교체·스냅은 유지한다. 필드 아이템 드롭도 32px, 꽃 드롭은 24px 유지. 흰색 부유 드롭은 참조 노드/탭 색과 테두리로 교체한다. 아이템 32px/꽃 24px 조작 영역은 고정, 테두리·면·아이콘이 0~4px 정수 부유(1.8초, 위상 분산)한다. 12×3px 그림자, 드래그 중 부유 중단/복원, 일시정지 및 종료 정리를 유지한다. 고정 판정 때문에 최고점에서 그림 상단 4px이 판정 영역을 벗어날 수 있다. 기존 꽃 배치와 순찰, 게임플레이 미구현 범위 유지.

## 현행 Garden 16 공통 팔레트

[UI·게임 공통 색상 가이드](./ui-color-guide.md)가 팔레트와 소재/역할 선정의 단일 설계 기준이다. `GardenPalette.hex`에 원본 16색을 정의하며 UI 역할 별칭은 `GardenPalette.reference`에서 관리한다. 기존 23색 UI 및 UI 전용 16색은 이전 변경 이력이다.

현행 전장·그림자는 #0D0D0D, HUD는 #161619, 일반 면·팝업 본문은 #3B3B4E, 제목은 #44445C, 선택 면·도안 내부 그리드선·슬롯 외곽은 #51516B, 일반 패널 외곽선은 #676777, 포커스는 #B0ACBD이다. 주요/보조/비활성 텍스트는 각각 #FFFFFF/#B0ACBD/#B0ACBD, 증가/감소는 #6ABA2C/#F46C7C. 잠김 면과 게이지 빈 영역은 #161619. 성공/실패는 밝은 제목과 상태색 외곽선으로 표현한다. 기존 1px 텍스트 그림자와 투명도, 정보창 하단 구분선 없음, 모든 크기·간격 유지.

기존 테스트 꽃·달팽이·손수레는 원본 데이터의 인덱스·알파·크기·배치를 보존하고 실제 표시는 원본 소재에 가까운 Garden 16 색을 사용한다. 수호자·보석 임시 도형도 Garden 16을 참조한다. 독립 카드 비교 페이지도 공통 팔레트를 참조한다. 신규 첨부 객체 자체의 추가는 범위 밖이다.

## 상단 HUD 다국어 폭 예약

기본 한국어, HUD 전용 미리보기 `?lang=ko/en/ja/es/zh`(지역 접미어 허용). 게임 전체 번역, 실제 언어 설정/저장, 언어별 숫자 포맷 변경은 구현하지 않는다. 기존 12px 글꼴 크기, 32px HUD, 좌우 7.5px 패딩, 후속 요소 간격 5px, 최대 시간 네 자리 시와 처치/보석 12자리 숫자 예약 유지. 5개 언어의 실측 최대 시간/처치 레이블 및 숫자 예약 폭을 고려해 동일한 세 열 폭을 결정한다. 완성도 그룹도 가장 긴 레이블 폭을 예약한다. 완성도 그룹 앞의 구분선은 제거하고 독립 우정렬한다. 게이지 오른쪽 끝 x=952.5 고정(시간 그룹 시작 x=7.5와 동일한 7.5px 외측 패딩), 레이블은 게이지 시작 x=794.5의 왼쪽에서 정확히 5px 간격으로 배치하므로 짧은 번역에서도 간격이 벌어지지 않는다. 게이지 채움은 공통 성장색 #6ABA2C를 적용한다. 기존 패딩 10px 버전에서는 실제 Chromium 5개 언어×3개 해상도(960×540, 1600×900, 1920×1080) 모두 동일 폭 167px, 게이지 x=792, 레이블 간격 5px 확인. 최신 패딩 버전의 검증은 변경 이력 참조. 번역 문자열의 모든 글리프가 기존 WOFF2 cmap에 있는지 fontkit으로 검증했다. 기존 회귀 포함 204/204 통과. ## 메뉴 및 팝업

모든 씬은 논리 960×540. 메뉴 테두리는 논리 1px(FHD에서 2물리 px)이며 호버 시 두께는 변경하지 않는다. 버튼 높이 24px, 인접 버튼/탭 간격 3px, 팝업 제목 띠 높이 32px, 기본 콘텐츠 패딩 10px, 별도 정보 영역 구분 기본 간격 20px. 일반 버튼 및 보조 설명 글꼴 12px, 주요 행동(새 게임·계속하기) 14px, 팝업 제목 18px(확인창 포함), 메인 타이틀 40px. 제목·버튼 글자의 가시 중앙 또는 가시 좌우 경계 기준으로 정렬하며, 실제 화면 배율 변경 시 다시 측정한다. 공통 `GardenUI.menuStyle`, `GardenUI.fontSize`, `GardenUI.inkBounds` 사용. 중앙 배치 버튼 그룹은 승인된 200px/110px 너비를 유지해 좌우 여백이 10px보다 클 수 있다. 패널 제목 띠, 일반 버튼 중성 테두리, 선택 밝은 테두리와 어두운 오버레이를 사용한다. 기능·문구는 기존 그대로이며 참조 게임의 메뉴 항목이나 기능을 복제하지 않는다.

## 렌더링 및 한계

- 전체 UI의 논리 크기·가시 간격과 실제 출력 배율 검증은 [UI 배율 감사](./ui-scale-audit.md)를 참조한다. 기존 객체 기준 간격과 실제 가시 간격을 구분하고, 앞으로는 AGENTS.md의 가시 간격 원칙을 적용한다.

- 최대 16:9 창 맞춤, 960×540 논리 좌표 유지. 실제 출력 버퍼는 CSS 화면 크기와 devicePixelRatio를 반영한 최대 16:9 물리 픽셀 크기. 1920×1080은 2배, 1600×900은 5/3배. Phaser Scale.NONE과 역 DPR 표시 배율로 CSS 크기 및 입력 좌표를 동기화한다. 기존 단일 씬의 카메라와 월드 배치를 유지하고 UI 렌더만 최종 픽셀 경계에 정렬한다.
- 기존 Fusion Pixel 10px Proportional KO Regular 및 NEAREST 유지. 텍스트는 실제 출력 배율(1배 미만 포함)에서 래스터화하고 정수 캔버스 크기와 텍스처 프레임 및 UV를 일치시킨다. 렌더 위치만 픽셀 경계로 정렬하며 논리 크기·정렬·문자 폭·원본 글리프는 변경하지 않는다. 네이티브 래스터의 안티앨리어싱은 유지하므로 비정수 배율에서 완전한 정수 픽셀 복제를 보장하지 않는다.
- UI 사각형은 네 외곽 귀퉁이의 1×1 논리 px을 제거한다(드롭·슬롯·장착/스냅·게이지·아이템 정보창·메뉴 버튼/패널). 사각형 채움은 최종 렌더링 버퍼의 정수 픽셀 경계에 맞춘다. 도안 헤더와 그리드는 각각 독립된 네 모서리 컷을 적용하고 3px 공백으로 분리한다. 도안 내부 공유선, 정원 셀 외형, HUD 띠, 이미지 크기는 유지한다. 정원의 공유선은 단일 텍스처에 출력 배율로 직접 래스터화하여 리사이즈 시 재생성하고, 축소에서도 최소 1물리 px로 표시한다(피치가 1물리 px 미만인 극소 창 제외). 인접 면의 물리 경계도 동일 좌표를 공유한다. 1px 컷 및 테두리는 FHD에서 2px. 정보창의 테두리는 명목 외곽 안쪽에 그린다. 참조 게임의 내부 렌더 방식과 동일하다는 의미는 아니다.
- `?preview=1`, `?hud=stress`, `?garden=24`(기본 24px 외형), `?garden=32` 및 `?garden=36`(내부 32px/외형 34px/피치 33px/최대 331px 비교 호환) 유지. `card-compare.html`의 독립 패딩 비교 내용은 유지하며 색만 참조 팔레트에 맞춘다.
- 실제 Chromium 회귀검증 스크립트 `tests/reference-ui.mjs`는 `feature/reference-ui`에서 실행한다. 640×360/960×540/1280×720/1600×900/1920×1080, HUD 스트레스, UI 배치/색, 드롭·장착·꽃·팝업·화면 전환을 확인한다. 실제 Chromium 131/131 검사 통과([실행 및 스크린샷 아티팩트](https://github.com/xcliming-svg/garden-test/actions/runs/43318950238)), JS 7개 구문 검사 통과. 사람 대상 시각적 선호 평가 및 다른 브라우저는 미실시.
