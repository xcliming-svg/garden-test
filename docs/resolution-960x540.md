# 960×540 · 24px 그리드 / 16px 이미지 UI 비교 브랜치

- 브랜치: `devel`, 최초 기준 main `7198cba` (2026-11-12). 960×540 시안을 병합한 뒤 실제 브라우저 비교에서 1위인 J안을 적용했다. [UI 비교 평가](./ui-metrics-benchmark.md) 참조.
- 상태: 사용자 요청에 따른 비교 실험. main의 확정 640×360 규격을 대체하거나 승인한 것이 아니다.
- 목적: 24px 타일을 기준으로 메뉴와 전장의 UI를 재설계한다. 8px 배수 강제보다 유사 픽셀 로그라이크 화면의 가독성·정보 위계·정보 밀도를 우선한다. 사용자 정정에 따라 정원과 하단 슬롯은 내부 24px + 외부 1px 프레임, 꽃/아이템은 16px 원본을 사용한다. 초기 단순 1.5배 확대안(`9f50ba5`)을 대체하며, 실제 게임 기능 및 최종 아트 추가는 범위 밖이다.

8px 모듈은 기준값이며 강제하지 않는다. 실제 용도에 맞는 공통 좌표·타일·간격·폰트 토큰은 `GardenUI`에서 정의하고 `GardenGameLayout`에서 참조한다. 기능적 선은 1px 유지. 정원은 24px 흙 내부 면의 네 변 외부에 각각 1px edge 프레임을 그려 26px 피치로 배치한다. 인접 칸의 독립 프레임이 맞닿으므로 흙 면 사이 2px이며 추가 공백은 없다. 기존 점유·인접 후보만 표시, 나머지 투명. 흙 면 bark 30% 알파, 외곽선 불투명. 선택 외곽선은 기존 프레임에 일치한다. 하단 슬롯은 내부 24px grid(비활성 soil), 외부 1px slot(비활성 edge). HUD는 높이 34px, 1×18px 구분선, 상하 8px 여백. 레이블 12px, 일반 수치 14px, 시간 22px로 강조한다. 일반 수치·시간·레이블의 실측 폭을 분리하여 예약하며, 기존 앞 3열 동일 폭 및 최대 표시 자릿수 계약을 유지한다. 게이지 외형 높이 14px, 내부 12px. 하단은 좌우 각각 222px(74px×3열), 바깥 여백 10px, 슬롯과 각각 100px 간격이다. 슬롯은 높이 44px 하단 내에서 상하 9px 여백을 가진다. 꽃·아이템 드롭 카드 및 장착 카드도 외형 26px, 내부 24px, 아이콘 16px, 내부 패딩 4px, 외부 프레임 1px를 공유한다. 9+1 구성 및 비용 999(8px 점선 아이콘 위, 10px 숫자 아래, 최대 2px 간격, 중앙 정렬)는 기존 UI 테스트용이며 실제 초기 4칸 설계는 변경하지 않는다. 정보창은 192px 폭, 내부 172px, 4px 행 간격 및 2px 줄바꿈 간격. 외곽 위치는 x=10~950, y=44~488 안으로 보정한다. 기존 색상·드래그·스냅·교체·정원/순찰 기능은 유지한다.

## 메뉴 및 팝업

모든 씬을 960×540 좌표로 통일한다. 메인·일시정지 주요 메뉴 버튼은 288×38px, 세로 간격 6px, 글꼴 20px로 행동을 강조한다. 기타 버튼은 높이 32px, 글꼴 12px(개발용 결과 버튼은 높이 24px). 기본/작은 표시 12px, 팝업 제목 20px, 메인 제목 40px. 메뉴 보더/구분선은 논리 1px 유지, 호버 두께 불변. 기존 Garden 32 역할 및 오버레이 투명도 유지.

## 렌더링 및 아트 한계

- 실제 캔버스는 창에 들어가는 최대 16:9 크기, 모든 씬의 카메라는 960×540 논리 좌표에 매핑한다. 1920×1080에서 배율 2, 1280×720에서 4/3.
- 기존 Fusion Pixel 10px Proportional KO Regular 원본, 실제 카메라 배율(최소 1) 래스터화, NEAREST 유지. 원본 폰트를 유지하되 가독성 평가 결과에 따라 10/12/14/16/20/22/40px를 역할별로 사용한다. 실제 Chromium 글리프 경계와 배치 검사를 수행했으며, 사람 대상 가독성 선호도 조사는 하지 않았다.
- 기존 꽃/손수레 16px 원본은 논리 16px로 표시하고 달팽이 12px 원본은 픽셀을 변경하지 않고 16px 캔버스 중앙에 투명 여백 2px로 배치한다(그림 자체는 12px). 새로운 고해상도 원본을 생성하지 않았다. FHD에서 꽃/손수레 원본 1px은 2×2 물리 픽셀, 전체 이미지는 32×32 물리 픽셀(main의 48×48보다 작음)이다.
- 실제 창 맞춤 정책은 기존대로 임의 비정수 배율을 허용한다. (이번 UI 조정에서는 배율 정책을 변경하지 않았다.) 8px 모듈은 0.5/1/1.5/2/4 등 배율에서 정수 크기를 만들지만, 4/3 등 임의 배율이나 1px 테두리/10px 폰트에서는 픽셀 크기가 정수가 아닐 수 있다. 완전한 픽셀 퍼펙트를 보장하지 않는다. 960×540, 24px 내부+1px 외곽선(26px), 2/4px 세부 간격, 홀수 십자 9px은 기존 목적상 예외로 보존한다.
- 기존 URL `?preview=1`, `?hud=stress` 유지. `?garden=24`는 기본 24px 흙 면과 동일하며, 대형 비교는 `?garden=32`로 명시한다(340×340 영역). 이전 `?garden=36`은 32px 대형 비교 호환 별칭이다. 대형 비교에서 최대 점유 가정 시 순찰과 HUD 중첩 가능성은 기존 제약이다.
- `card-compare.html`은 main의 16px 아이콘 원본 및 기존 패딩 비교를 그대로 유지하는 별도 비교 도구이다.

## 검증

- [10개 UI 후보 실제 Chromium 비교 평가](./ui-metrics-benchmark.md): 후보별 107개 검사(총 1070개) 통과. 점수 1위 J안(94.25점)을 `devel`에 동일하게 적용했다. 640×360, 960×540, 1280×720, 1920×1080에서 글꼴과 UI 경계, 기존 화면 전환, 장착·교체·꽃 배치·잠김 거부 등을 검사했다.
- 실제 게임 화면 캡처 및 점수 원본은 [최종 GitHub Actions 실행](https://github.com/xcliming-svg/garden-test/actions/runs/43215418688) 아티팩트 참조. 실제 사람의 선호도, GPU 성능, 다른 브라우저 및 OS에서의 검증은 미실행.
- 게임플레이·저장·해금·실제 데이터 등 기존 미구현 범위는 유지한다.
