# 960×540 전장 논리 해상도 비교 브랜치

- 브랜치: `feature/resolution-960x540`, 기준 main `7198cba` (2026-11-12).
- 상태: 사용자 요청에 따른 비교 실험. main의 확정 640×360 규격을 대체하거나 승인한 것이 아니다.
- 목적: 상대적 화면 배치를 거의 그대로 유지하면서 높은 논리 해상도의 UI 표시를 비교한다. 실제 게임 기능 및 최종 아트 추가는 범위 밖이다.

## 렌더링 및 아트 한계

- 실제 캔버스는 기존과 동일하게 창에 들어가는 최대 16:9 크기이고 게임 카메라가 960×540 논리 좌표에 매핑한다. 1920×1080에서 게임 카메라 배율은 3→2, 1280×720에서는 2→4/3이다.
- 기존 Fusion Pixel 10px Proportional KO Regular 원본, 실제 카메라 배율(최소 1) 래스터화, NEAREST 유지. 글자의 물리 크기는 거의 동일하며 글꼴 원본 디테일을 높인 것은 아니다.
- 기존 꽃/손수레 16px, 달팽이 12px 원본의 텍스처를 24px/18px 논리 표시 크기에 매핑한다. 새로운 고해상도 원본을 생성하지 않았다. 1080p에서 원본 1px의 물리 크기는 기존과 같은 약 3px이므로 이미지 자체의 픽셀화가 줄어든다고 보장하지 않는다. 새 24px/18px 원본 아트는 별도 작업이다.
- 기존 URL `?preview=1`, `?hud=stress` 유지. 기존 비교 `?garden=24`는 상대 크기를 유지해 36px 흙 면(370×370 영역)으로 표시한다. 이 모드에서 최대 점유 가정 시 순찰과 HUD 중첩 가능성은 비교 모드의 기존 제약이며 변경하지 않는다.
- `card-compare.html`은 main의 16px 아이콘 원본 및 기존 패딩 비교를 그대로 유지하는 별도 비교 도구이다.

## 검증

- JavaScript 7개 파일 구문 검사 통과.
- 기본, HUD 스트레스, 정원 비교 모드 각각 21개 모의 실행 검사(합계 63개) 통과: 논리 좌표, 도안, 슬롯, 텍스처 매핑, 카메라 배율, 흙 면, 아이템 드래그·스냅·장착·교체·잠김 거부, 꽃 배치·일시정지 취소, 순찰, 도안 접기/펼치기, 리사이즈, 종료 리스너 해제.
- 모의 Phaser/Canvas 객체 사용. 실제 브라우저 렌더링, 폰트 실측, 픽셀 가독성, GPU 성능 및 사용자 선호도는 검증하지 않았다.
- 게임플레이·저장·해금·실제 데이터 등 기존 미구현 범위는 그대로이다.
