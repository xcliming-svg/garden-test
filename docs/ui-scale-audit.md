## 기존 객체 기준과 실제 가시 간격의 차이
- 상단 HUD의 과거 레이블-수치/게이지 간격 5px은 텍스트 객체의 폭 기준이었다. 현재는 아래 HUD 및 메뉴 공통화 결과로 대체되었다. 변경 전 브라우저 캡처 [43356756076](https://github.com/xcliming-svg/garden-test/actions/runs/43356756076)의 한국어 FHD 스트레스 화면을 25% 대비 기준으로 실측하면 시간→수치 14px(논리 7), 처치 수→수치 14px(7), 보석→수치 10px(5), 완성도→게이지 14px(7)이다. 즉 실제 가시 간격은 모두 5px로 일치하지 않는다. 화면 배율 문제와 별개로 글리프 좌우 여백이 포함된 결과다.
- 정보창의 과거 구현은 행/줄 간격 5/4px을 텍스트 객체/Phaser 줄 간격으로 적용했다. 현재 가시 패딩·행 간격은 아래 공통화 결과로 대체되었다. 교체 미리보기의 960×540 캡처에서 밝은 글자 전경(최대 RGB≥140) 행 공백은 여러 행에 걸쳐 8px, 제목-본문 경계에서 13px로 관찰된다. 줄바꿈 및 제목 영역의 추가 행 간격도 있다. 실제 가시 간격을 5/4px으로 확정한 결과가 아니다.
- 당시에는 상단 HUD 및 정보창의 기존 간격을 유지했다. 현재 정보창과 상단 HUD는 사용자 요청으로 가시 5px 적용 대상으로 변경했다. 최신 검사 결과는 아래 공통화 기록을 참조한다.
- 비정수 배율에서 원본 글리프의 안티앨리어싱/래스터화 차이, 월드 스프라이트의 NEAREST 샘플링은 완전히 같은 물리 픽셀 모양을 보장하지 않는다. 1논리 px 선이 물리 1px 미만인 경우 픽셀 재현에 한계가 있다. 브라우저와 OS·GPU별 차이, 사람의 가독성 및 극소 창 크기는 이번 검사 범위 밖이다.

## 카드와 정보창의 외곽 간격 5px

- 정보창 내부 가시 패딩과 외부 카드 간격을 같은 5논리 px로 연결. 실제 외곽선 안쪽 테두리 방식에 맞춰 기존 중앙 스트로크 보정을 제거했다. 5개 출력에서 드롭 좌우 스크린샷 공백 3/5/7/8/10물리 px, 슬롯 위 4/5/6/9/10물리 px(HUD 경계 유지, 비정수 배율 최대 1물리 px 오차). 첫 실행의 HUD 경계 측정 오류 3건을 수정하고 [Chromium 896/896 통과](https://github.com/xcliming-svg/garden-test/actions/runs/43374973256), 코드 `36aeb48`. DPR2, 장착/교체 및 기존 회귀 검사 통과. 실제 드롭·장착 화면을 확인했으며 다른 OS·브라우저는 미검증.

## Garden 16 색감 복구

이전 청회색 팔레트는 역사적 기록이다. 최신 16색은 참고 UI의 색 관계와 객체 소재 색을 반영하고 실제 UI·스프라이트에 적용한다. 원본 데이터는 보관한다. [공통 색상 가이드](./ui-color-guide.md)를 따른다. 기하·배율·입력 계약은 유지한다.

- [Chromium 874/874 통과](https://github.com/xcliming-svg/garden-test/actions/runs/43371968886), `594b010`. 원본 색 예외 없이 실제 표시용 샘플과 설치 텍스처가 공통 16색의 데이터/알파와 일치하고 기존 UI 가시 간격·입력 계약을 유지함을 확인했다. 원본 보관 RGB와 투명도 합성 픽셀은 표시용 팔레트 정의와 구분한다.
