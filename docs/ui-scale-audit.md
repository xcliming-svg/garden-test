## 기존 객체 기준과 실제 가시 간격의 차이
- 상단 HUD의 레이블-수치/게이지 간격 5px은 텍스트 객체의 폭 기준이다. 변경 전 브라우저 캡처 [43356756076](https://github.com/xcliming-svg/garden-test/actions/runs/43356756076)의 한국어 FHD 스트레스 화면을 25% 대비 기준으로 실측하면 시간→수치 14px(논리 7), 처치 수→수치 14px(7), 보석→수치 10px(5), 완성도→게이지 14px(7)이다. 즉 실제 가시 간격은 모두 5px로 일치하지 않는다. 화면 배율 문제와 별개로 글리프 좌우 여백이 포함된 결과다.
- 정보창은 기존 행/줄 간격 5/4px을 텍스트 객체/Phaser 줄 간격으로 적용한다. 교체 미리보기의 960×540 캡처에서 밝은 글자 전경(최대 RGB≥140) 행 공백은 여러 행에 걸쳐 8px, 제목-본문 경계에서 13px로 관찰된다. 줄바꿈 및 제목 영역의 추가 행 간격도 있다. 실제 가시 간격을 5/4px으로 확정한 결과가 아니다.
- 위 두 영역의 기존 간격을 사용자 확인 없이 다시 지정하지 않는다. 하단의 요청된 가시 3px을 우선 수정하고, 나머지 가시 간격은 별도의 조정 대상으로 구분한다.
- 비정수 배율에서 원본 글리프의 안티앨리어싱/래스터화 차이, 월드 스프라이트의 NEAREST 샘플링은 완전히 같은 물리 픽셀 모양을 보장하지 않는다. 1논리 px 선이 물리 1px 미만인 경우 픽셀 재현에 한계가 있다. 브라우저와 OS·GPU별 차이, 사람의 가독성 및 극소 창 크기는 이번 검사 범위 밖이다.

- [실제 Chromium 최종 회귀 316/316 통과](https://github.com/xcliming-svg/garden-test/actions/runs/43357379414), 코드 커밋 `fdc2298`. 최초 두 실행의 축소 배율/회색 글자 고정 밝기 기준 및 아이콘 끝행 누락을 수정한 결과다.
- 모든 해상도에서 도안 두 외형, 슬롯 10개의 외형 및 배치, 상하 HUD 경계, 게이지의 실제 출력 좌표가 반올림 예상 경계와 일치했다(40개 물리 기하 검사 통과). 메뉴·팝업 명시 크기 및 주요 3px 버튼 간격, 기존 오브젝트·입력·언어·정보창·DPR 2·비16:9 검사도 통과했다.
