## 사용자 정정 — 고정 순서 제거
돌멩이 두 장 후 부메랑은 좋은 플레이 경험의 사례일 뿐 강제 획득 순서가 아니다. 현재 정사각형은 돌멩이/부메랑 각각 50% 복원 추첨, 런당 최대 3장. 기존 선정 수치와 상한은 유지. 위의 고정 순서 결과는 역사적 실험이며 현행 규칙의 증거가 아니다. 새 무작위 조건은 seed27101–27116 세 정책 .05 및 seed28101–28116 일반 .025의 대조군/후보 128회로 별도 비교한다. 기존 gate를 보고하되 무작위 순서 자체를 강제 순서로 되돌리지 않는다. 브라우저 테스트는 두 종류의 RNG 입력에 실제 생성 카드가 일치하고 재시작/상한이 유지되는지 검사한다.
