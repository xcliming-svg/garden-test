# UI 공통 간격 가이드

- 적용 대상: Garden Test의 신규 UI 및 기존 UI 개선 작업. 현재 devel의 960×540 논리 좌표계를 기준으로 한다.
- 목적: 모든 간격을 한 값으로 강제하지 않고, 요소의 관계와 역할에 맞는 일관된 간격 체계를 사용한다.
- 현행 개별 화면의 확정 크기·좌표·색상·예외는 [현행 UI 규격](./resolution-960x540.md)을 따른다. 이 가이드는 기존 확정 규격을 자동 변경하는 지시가 아니다.

## 1. 공통 간격 체계

| 논리 간격 | 역할 | 적용 예 |
| --- | --- | --- |
| **3px** | 밀접한 요소 사이 | 하단 슬롯 사이 및 상하 여백, 도안 제목 박스와 그리드 사이, 인접 메뉴 버튼·설정 탭 사이, 하단 능력치 레이블·수치 및 확장 비용 아이콘·수치 사이 |
| **5px** | 소형 UI 내부 패딩 및 정보 간격 | 도안 제목 패딩, 정보창 상하좌우 패딩과 본문 행 간격, 카드와 정보창 외곽선 사이, 상단 HUD 레이블/아이콘과 수치·게이지 사이 |
| **10px** | 일반 패널 내부 기본 여백 | 설정·도감·일시정지·확인·결과 팝업의 콘텐츠 경계, 좌우 정렬 및 하단 버튼 여백 |
| **20px** | 서로 다른 정보 영역의 구분 | 메뉴 섹션, 독립 콘텐츠 블록 사이의 기본 간격 |

간격은 정보의 연관성에 따라 선택한다. 같은 그룹 내부의 요소는 밀접하게, 다른 그룹 사이에는 더 넓게 배치한다. 같은 역할에는 동일한 공통값을 재사용하며 별도의 수치를 임의로 추가하지 않는다.

## 2. 패딩·정렬 적용 원칙

- 패딩은 컨테이너 외곽과 내부 콘텐츠 사이의 여백, 요소 간격은 인접 요소의 가시 경계 사이의 빈 공간이다.
- 지정된 가시 간격은 글자의 실제 전경 또는 도형 외곽선을 기준으로 한다. 투명한 글리프 여백과 그림자는 가시 간격에 포함하지 않는다.
- 좌측 정렬된 텍스트의 오른쪽 패딩은 최소 여백이다. 글자를 강제로 늘리거나 줄여 양쪽 여백을 맞추지 않는다.
- 중앙 정렬된 버튼 묶음은 확정된 버튼 너비와 중심을 유지한다. 이때 실제 좌우 여백은 기본 패딩보다 넓을 수 있다.
- 동일 행·열의 중심선, 좌우 경계 및 가시 글자 기준선을 공유한다. 공통 글꼴과 원본 에셋의 비율을 보존한다.
- 관련 공통 코드 값은 `GardenUI.menuStyle`, `GardenUI.inkBounds`, `GardenGameLayout.hud`, `GardenGameLayout.spec` 및 각 UI 레이아웃 정의를 참조한다. 현재 코드에 존재하는 다른 간격 토큰을 일괄 치환하지 않는다.

## 3. 해상도 변경

| 논리 해상도 960×540 기준 간격 | 640×360 | 960×540 | 1280×720 | 1600×900 | 1920×1080 |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 3px | 2 | 3 | 4 | 5 | 6 |
| 5px | 3 | 5 | 7 | 8 | 10 |
| 10px | 7 | 10 | 13 | 17 | 20 |
| 20px | 13 | 20 | 27 | 33 | 40 |

표는 논리 간격에 출력 배율을 곱해 가장 가까운 물리 픽셀로 반올림한 목표값이다. 비정수 배율에서는 각 외곽선의 픽셀 스냅으로 실제 기하 간격이 1물리 px 이내에서 달라질 수 있다. 정수 배율의 목표 간격은 정확히 일치해야 한다. 화면 크기, DPR 및 비16:9 창에서도 단일 논리 좌표계와 입력 매핑을 유지한다. 구체적인 측정 기준 및 실제 검증 결과는 [UI 배율 감사](./ui-scale-audit.md)를 참조한다.

## 4. 기존 확정 예외

공통 체계는 기본 설계 기준이며, 다음과 같은 승인된 별도 규격을 자동으로 변경하지 않는다.

- 상단 HUD 외측 패딩과 HUD→도안 상단 여백: 7.5px (텍스트 객체 기준).
- 정보창 줄바꿈 설정: 4px (Phaser 줄 간격 설정이며 실제 행 사이 가시 5px과 구분).
- 하단 능력치 수치와 증감값 사이: 2px (텍스트 객체 기준).
- 꽃·아이템·슬롯 내부 아이콘 여백: 각 외형과 원본 이미지 크기에 따라 결정되는 별도 규격.
- 1px 테두리, 2px HUD 경계, 버튼 높이 및 폰트 크기 등은 간격 체계와 별도로 관리한다.

새로운 예외가 필요하면 역할·기존 규격과의 차이·근거를 현행 UI 문서에 기록하고 사용자 승인 범위를 지킨다. 현재의 확정 규격과 가이드가 충돌하면 해당 화면의 현행 확정 규격을 우선 확인한다.

## 5. 작업 및 검증

새 UI를 배치할 때 요소의 관계에 따라 3/5/10/20px 중 적절한 기본 간격을 선택한다. 구현 시 공통값을 활용하고, 가시 경계·정렬·겹침·잘림 및 실제 화면 배율을 확인한다. 기존 UI 수정은 관련 회귀 검사를 수행한 후 현행 규격과 변경 이력을 함께 갱신한다.

이 문서는 세부 UI 디자인 가이드이며 저장소 전체의 개발 절차는 [AGENTS.md](../AGENTS.md)를 따른다.
