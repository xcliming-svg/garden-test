# 기본 플레이 통합 (devel)

2026-11-19 · feature/playable-garden-loop · Phaser 3.90.0 유지. 최신 devel 5362528의 [무기 밸런스 v1](./weapon-balance-v1.md) 및 물방울 요정 카드 구현을 보존하여 통합.

## 사용자 확정
- 새 게임: 중앙 2×2 만개 꽃 4개, 나뭇잎 요정 1명. 처음 열린 슬롯 4개 중 0번에 Lv.1 돌멩이 **이미 장착**. 나머지 3개 비어 있고 확장 1개 표시. 시작 카드 획득/드래그 불필요.
- 적은 외곽에서 꽃까지 진입하고 처치되기 전에는 퇴장하지 않는다. 꽃 근처에서 windup/strike/recover/ready 반복, 최대 10px 공격 준비 위치(기존 모션 유지). 목표 소멸 시 현재 좌표에서 가장 가까운 살아 있는 꽃으로 이동.
- 적 처치마다 보석·하트·꽃 카드·아이템 카드 중 정확히 하나. 물방울 요정은 장착형 카드로만 합류하고 돌멩이만 사용.
- 상단 실시간 플레이 시간(일시정지 제외), 누적 처치, 소비 가능한 보석, 도안 완성도. 보석 구매 시 내부 잔액 즉시 차감, 표시값은 0.65초 역방향 카운트다운.
- 10개 슬롯에서 확장 종료. 초기 4개+확장 1개만 보이며 열린 슬롯 중심 정렬. 선택 콤보박스·미리보기 상태 텍스트·비교 파라미터 기본 실행에서 제거.

## 임시 밸런스 (미확정 수치는 추후 플레이테스트)
| 항목 | 값 |
| --- | --- |
| 10×10 도안 | 중앙 4×4, 총 16칸, 기존 6종 꽃 |
| 완성도 | 도안 위치·종류 일치하고 만개한 칸 수 / 16, 내림. 도안 밖 꽃 배치 금지. 칸별 미배치/성장 중/완료/불일치 상태 표시 |
| 꽃 | 100 에너지, 0에서 제거, 8초마다 성장 1→2→3(16초 만개), 만개 후 유지 |
| 잘못 심은 꽃 | 만개 후 도안 붉은 배경과 정원 꽃 우하단 × 표시. 모든 꽃은 3초 마우스 좌클릭 유지로 제거 가능. 녹색 실선 테두리가 역방향으로 줄어들고 완료 시 꽃 제거. 중간 해제/칸 이탈/일시정지 시 취소. 직접 교체 금지 |
| 하트 | 살아 있고 에너지 1~99인 꽃만 대상. 최저 에너지 꽃 +20, 최대 100. 모든 꽃이 정상일 때 바닥에 유지(기존 수명 후 만료), 이동 중에도 대상 재평가. |
| 드롭 | 보석 69%, 하트 10%, 꽃 18%, 일반 카드 3% 기본 추첨. 일반 카드 생성 최소 간격 30초(제한 중 일반 당첨은 보석으로 대체); 꽃은 도안 미충족 종류에 75% 우선 |
| 바닥 카드 | 전체 10×10 정원·도안·HUD 밖에 생성(5px 여유, 4px 부유 고려), 가능하면 다른 카드와 겹치지 않게 처치 위치에 가장 가까운 후보 선택. 45초 후 소멸, 드래그 중 만료 시간 정지, 부유 1.8초 연속 코사인 |
| 적 | 시작 180초 애벌레만, 첫 구간 3초 간격·3마리 상한. 4분 30초까지 이전 첫 도안 웨이브 유지, 이후 [시간대별 웨이브](./survivor-progression.md) 출현 밀도 증가(기존 체력/피해 유지). 기존 생존 적은 유지, 이동 속도 최소값 유지. |
| 무기 | 최신 무기 밸런스 v1의 공격별 피해/쿨타임/사거리/상성 및 예측 조준 유지; 돌멩이 Lv.1 피해 10, 쿨타임 0.8초, 사거리 280px. 물방울 요정도 같은 돌멩이 규칙 |
| 신발·방패 | 이동 속도 +10(최대 80), 꽃에 가해지는 공격 피해 6 감소 |
| 슬롯 확장 | 40 / 60 / 85 / 115 / 150 / 200 보석, 최대 10개 |
| 종료 | 모든 꽃 소멸 → 실패, 도안 100% → 성공; Game 씬을 일시정지하여 최종 전장과 HUD를 그대로 보존하고 우측 결과 팝업만 띄우고 기존 요정 감정 애니메이션만 독립 재생. 전체 10×10 정원 및 순찰 영역과 겹치지 않음. 시간·처치·잔여 보석·완성도. 새 게임/메인 메뉴 선택 때 이전 Game 종료 |

아이템은 기존 장착 규칙 그대로이며 중복 장착 가능. 별도 강화 또는 레벨업을 추가하지 않는다. 교체로 마지막 피해 수단이 없어지는 것은 방지한다. DPS는 단일 대상 기준 명목 피해/주기이며 범위·관통·감속 효과에 따라 실제 피해는 달라진다. 경험치·레벨업·보스·영구 성장·저장·오디오·최종 밸런스는 미구현/미확정.

## 실행 및 모듈
- `index.html`: 기본 플레이 전용. URL 비교 파라미터는 제거.
- `lab.html`: 기존 비교용 URL과 개발용 셀렉트·왕복 적 등 이전 미리보기 보존. 회귀 테스트는 이 진입점 사용.
- `src/run-rules.js`: 순수 규칙/재화/완성도/시간, `src/run-drops.js`: 런 드롭·승패·HUD 업데이트.
- 기존 꽃, 적, 요정, 무기, 카드, 렐릭 및 UI 모듈을 확장. SVG 원본/팔레트/엔진 변경 없음.
