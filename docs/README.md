# 개발 문서

> **960×540 비교 브랜치:** 이 문서의 기존 640×360 수치와 확정 이력은 main 기준으로 보존한다. 현재 브랜치의 실험 규격 및 예외는 [960×540 비교 문서](./resolution-960x540.md)를 우선 참조한다. main 규격 변경 승인 또는 게임플레이 구현을 뜻하지 않는다.

## 문서 읽기 기준

- **확정 설계:** 사용자와 합의한 목표나 규격. 코드에 없으면 구현 완료를 뜻하지 않는다.
- **적용 구현:** 현재 저장소 소스에 존재하는 기능이나 UI. 실행 검증 여부와 구분한다.
- **미구현·미정:** 확정 설계의 남은 작업 또는 아직 결정하지 않은 사항. 추가 개발을 승인하는 목록이 아니다.

현행 UI 규격은 ui-spec.md에서 먼저 확인하고 상세 좌표와 전체 팔레트는 ASSET_SPECS.md를 따른다. 변경 이력에는 대체된 시안도 남기되 현행 문서와 구분한다.

구현 변경 시 해당 시스템의 현행 문서를 갱신하고 변경 이력에도 동일 작업의 효과를 기록한다. 변경 없는 시스템을 반복해서 기록하지 않는다. 과거 설계가 대체되면 현행 문서에는 최신 확정안을 유지한다.
