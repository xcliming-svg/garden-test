## 0. 용어와 결정 상태

- **고정**: 사용자가 명시적으로 정한 게임 규칙. 자동 최적화가 임의 변경하면 안 됨.
- **기준선**: 화면/게임 구조상 현재 채택된 값. 바꾸려면 별도 기획 검토가 필요한 값.
- **조정**: 현재 숫자는 있으나 앞으로 목표 KPI에 맞춰 다시 실험해야 하는 잠정값.
- **파생**: 다른 값의 공식으로 계산되므로 별도의 독립 입력값이 아니다.
- **목표 미정·미구현**: 실제로 원하는 플레이 결과 또는 필요한 기능을 먼저 정의해야 함.

**주의**: 내부 유닛과 노출 시간을 혼동하지 않는다. 초당 수치, 분당 수치, 누적값, 한 화면 최대값은 서로 다른 지표다. 아래 숫자는 해상도에 무관한 **960×540 논리 px**와 **게임 시간 초/분**을 기본으로 한다.

모든 수치는 `ID / 이름 / 단위 / 소스 코드 경로 / 현행값 / 목표값 또는 허용범위 / 고정여부 / 영향받는 KPI / 테스트 방법 / 근거 링크 / 결정일 / 버전`을 함께 기록한다. **정책/난수 시드/실행 환경**까지 기록하지 않으면 변경 전후를 재현할 수 없다.

## 8. 유효 범위와 별도 목록으로 관리할 것

- **게임 미구현**: 시간대별 보스/퀘스트/특수 웨이브, 치명타/관통의 공통 성장 스탯, 영구 진행/이어하기/배속 자동화 등. 임시 숫자를 현재 게임 값으로 쓰지 않는다.
- **기존 비교용 모드**: 구형 6×6·14×6/20장비 슬롯, 11요정, 200동시 적, 과거 도안별 출현 타임라인, 꽃 에너지 HP, 구형 장비 드롭 확률 등은 **현재 `devel` 기본 생존 게임의 수치가 아니다**.
- **순수 UI/연출 디자인**: 팔레트 색상·패널 패딩·테두리 두께 등은 게임 결과에 영향을 주지 않으면 이 문서에서 제외한다. 단 공격 경고, 수확 대기, 투사체 가독성 및 프레임 시간에 영향을 주는 값은 포함한다.
- **현행 소스의 주석**은 오랫동안 업데이트되지 않은 문장이 있을 수 있으므로 주석의 목적 설명과 실제 계산식을 분리했다.
