# 10쌍 34px 하단 HUD (main 기반 devel)

## 기준과 범위
- 기준 소스: `main` 브랜치. `devel`은 과거 실험의 소스 상태를 복구하지 않고, 이 기준에 본 화면 변경만 적용한다.
- `devel` 기본 게임 화면: 10쌍 × (34×34px 2칸), 좌측 x=10에서 시작. 쌍 내부 간격 0px, 1px 공용 세로선, 쌍과 쌍의 간격 3px.
- 10쌍 전체 너비: 10×68 + 9×3 = **707px** (x=10~717).
- 우측 능력치 3열: 마지막 슬롯 끝 x=717로부터 3px 띄워 x=720에서 시작, 화면 오른쪽 10px 패딩을 유지하여 x=950까지 **230px을 균등 분할**. 각 열은 약 76.67px(기존 70px 대비 약 6.67px 확대). 라벨과 수치의 열 중앙 좌표는 x=758, 835, 912. 별도의 좌측 빈 20px을 남기지 않고 3열이 잔여 공간을 사용한다.
- 슬롯 y=503~537, 2px 상단 HUD 경계선 아래 3px, 화면 하단에서 3px. 하단 HUD 높이 44→42px, 전장 높이 +2px.
- 필드에 떨어지는 일반 아이템 카드도 외형 **34×34px**로 조정. 장착 카드/고스트/명시적 상호작용 영역도 34px. 아이콘 크기·원본 SVG·색상은 유지.
- 한 쌍의 **왼쪽 칸만 기존 10개 실제 장착 슬롯**에 매핑된다. 오른쪽 칸 10개는 추가 조작이 없는 시각적 자리다. 구매·장착·교체·전투·드롭·도안·스테이지 규칙과 슬롯 상한(10)은 변경하지 않는다. 추가 10칸의 실제 기능은 승인되지 않았으므로 구현하지 않는다.
- 명시적 `GardenSimulationConfig` 및 `lab.html` 미리보기는 기존 슬롯 규격과 배치 유지. `main`의 소스와 Pages 루트는 변경 없음.

## 검증
- `tests/paired-slot-hud-browser.mjs`: 960×540/1280×720에서 10쌍 실제 렌더 객체·입력 영역·2px 경계선 외 상하 3px·우측 스탯의 3열 균등 너비/중앙 정렬/영역 경계·34px 필드 카드·슬롯 구매 이동 없음·브라우저 오류 검사.
- 변경과 기존 플레이 루프의 회귀 검증은 `.github/workflows/paired-slot-hud.yml`에서 수행한다.
