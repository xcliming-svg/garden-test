# devel 정원 물주기·꽃 수확 2×2 비교 — 2026-11-21

> 작업 범위: 기본 `index.html`의 devel 생존형 정원. 6×6 꽃 종류별 사분면(해바라기·장미·수국·라벤더)을 유지하고 4개 화단 단위로 물주기/성장/수확을 시험한다. 원본 SVG, `main`, 명시적 과거 비교 `lab.html`은 변경하지 않는다.

## 비교 URL

| 화단 표현 | 자동 수확 | Space 수동 수확 |
| --- | --- | --- |
| A: 중앙 큰 꽃 한 송이 | `/devel/?plot=a&harvest=auto` | `/devel/?plot=a&harvest=space` |
| C: 3×3 꽃다발 아홉 송이 | `/devel/?plot=c&harvest=auto` | `/devel/?plot=c&harvest=space` |

- 비교 사이트 루트: https://xcliming-svg.github.io/garden-test/
- 기본 `/devel/` 화면은 `plot=a&harvest=auto`에 해당한다. 파라미터를 지정하지 않거나 잘못 입력한 경우 기본값으로 돌아간다.
- `?farm=legacy`는 이전 devel 생존형 20칸 장착/물요정 조합 비교를 유지한다. 과거 모델·실제 브라우저 회귀 시험에서도 명시적으로 이 URL을 사용한다.

## 화면/게임 상태

1. **정원:** 6열×6행(139×139 논리 px); 왼쪽 위 해바라기, 오른쪽 위 장미, 왼쪽 아래 수국, 오른쪽 아래 라벤더. 화단별로 3×3 공간 한 개(총 4개 화단)를 사용한다.
2. **A 표현:** 각 3×3 화단에는 중앙의 확대된 SVG 한 송이만 표시하고 주변은 별도의 흙 화단으로 남겨 둔다. 프로그램 내부의 논리 셀 36개는 적 목표·화단 경계 호환성을 위해 유지하되, 확대 이미지 외 8개/화단은 숨긴다.
3. **C 표현:** 각 3×3 화단에 기존 크기의 꽃 SVG 9개를 모두 표시한다. 수확물은 개별 꽃 9개가 아니라 꽃다발 하나로 계산한다.
4. **세 성장 단계:** 원본 `_01.svg`(잎), `_03.svg`(중간/봉오리), `_04.svg`(만개)를 사용한다. 성장 진행률 0–33%→초기 잎, 34–66%→중간, 67–100%→만개. 각 화단 내부 이미지는 화단 공유 진행률과 함께 변화한다.
5. **물방울:** 잎사귀 요정 앞에 표시한다. 시작 물 0/100, 적 한 마리 처치당 +20, 100이면 `MAX`. 보석 획득/아이템 카드 드롭을 생존 수확 모드에서는 사용하지 않는다.
6. **Space:** 누르고 있으면 잎사귀 요정의 순찰이 멈추고 가까운 화단으로 초당 물 25를 공급한다. 물이 줄어드는 양만큼 해당 화단 성장률이 오른다. 키를 놓으면 순찰 재개.
7. **자동 수확:** 진행률 100 도달 즉시 수확물 +1, `+1` 표시, 해당 화단 초기 잎으로 리셋. 같은 Space 홀드 중에 연속으로 수확하지 않도록 재입력을 요구한다.
8. **수동 수확:** 진행률 100을 유지하고 `MAX` 표시. Space를 놓았다가 새로 누르면 그 화단에서 +1 획득/초기화한다. 수동 수확에 별도 물은 필요하지 않다. 키 자동 반복은 새 입력으로 간주하지 않는다.
9. **하단:** 기존 20개 장착 슬롯 및 공격/방어/이속 스탯을 표시하지 않고 네 종류별 꽃/꽃다발 소지 수 `해바라기 0 · 장미 0 · 수국 0 · 라벤더 0`로 대체한다.
10. **요정/적:** 나뭇잎 요정 한 명만 순찰하고 기존 나뭇잎 요정 기본 자동 발사(5발)를 사용한다. 이전 물요정 장착·부메랑 조합/아이템 드래그는 수확 모드에서 사용하지 않지만 `farm=legacy`로 다시 볼 수 있다. 적의 기존 이동과 피격/퇴장 시스템은 재사용한다.

## 범위와 검증

- 화단 생장과 수확은 논리적 4개 화단 단위이며, 피해를 받는 게임 속 36개 논리 셀의 HP는 이 실험의 성장 게이지와 독립이다. 잎~만개 단계 시각화는 현재 화단 물주기 진행도를 우선한다.
- 수치는 A/C 및 수확 입력의 가독성·사용성을 빠르게 비교하기 위한 초기 임시 값이다. 적 물 획득량 +20, 물 보유량 100, 물 소비/성장률 초당 25는 이후 별도 밸런스 조정 가능하다.
- **자동 검증:** `tests/garden-harvest-model.mjs`는 4개 설정 조합, 6×6 매핑, MAX 물 저장, 성장 경계, 수확 초기화, 플롯별 카운트를 확인한다. `tests/garden-harvest-browser.mjs`는 실제 Phaser+Chromium에서 네 조합, 960×540/1280×720 배치, 적 처치 물 획득, Space 정지/물주기/해제, 3개 SVG 성장, 자동/수동 수확, 하단 수량, 물요정·장착 슬롯 제거를 검사한다. 이전 생존형 수동 장착 모드는 `tests/survival-fairy-pairs-browser.mjs`의 `farm=legacy`에서 별도로 회귀 확인한다.
- 기능/자동 검사에서 실제로 동작하는 부분과 시각적 가독성·동작감 평가(사람 플레이 필요)는 구분한다.
