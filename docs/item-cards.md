> **devel 나뭇잎 요정 장착 무기:** 기본 새 게임은 적 없이 시작하며 하단 슬롯에 장착한 무기는 나뭇잎 요정만 자동 발사한다. 여러 무기 독립 발사 및 교체 반영. 신발·방패는 공격 없음. 셀렉트는 무장착 시 시각 비교 전용. `?enemies=1&weapons=1`에서 실제 적 피해/감속·처치 드롭 확인. 기존 명시적 전투 비교는 유지. [무기 규격](./hero-weapon-preview.md). 전장 공격 SVG는 카드 긴 변 24px와 별개로 가시 세로 높이 16/22/24/28/44px를 적용하며 부메랑만 긴 변 28px로 맞춘다. 빗자루는 설치점 주변을 회전한다.


## 실제 보석·하트 획득 (자동 공격 모드)

- `?enemies=1`에서 처치한 적의 바닥 위치에 보석 1개(100%)와 독립 확률 10%의 하트 1개를 생성한다. 원본 비율의 기존 12px SVG 재사용. 이동·퇴장으로 사라진 적은 보상을 생성하지 않는다.
- 보석·하트 공통: 나뭇잎 요정 위치에서 정원 바깥쪽을 향하는 전체 100° 부채꼴(좌우 50°)과 공격 사거리 550 논리 px(투사체 속도 220×수명 2.5초) 이내에서 흡수 개시. 순찰 위치에 따라 부채꼴 축이 연속 회전하며 모서리 우선순위 없음. 12px 근접 및 순찰 내부 드롭은 예외(내부는 반대 방향 부채꼴). 사거리 밖에 생성될 극소수 드롭은 생성 시에만 사거리 안으로 보정. 보석은 주인공 추적, 하트는 최저 에너지 꽃 추적. 초기 0.25초 착지, 수명 최소 최대(20초, 한 바퀴+1.25초), 흡수 중 소멸 없음. 물 요정은 획득 개시하지 않는다.
- 꽃별 에너지 최대 100, 적의 완료된 공격당 15 감소(0 하한). 하트는 정원 내 최저 에너지 꽃을 자동 추적, 접촉 시 20 회복(100 상한). 동률이면 작은 격자 인덱스 우선, 모두 가득 차도 획득하며 최대 에너지를 넘겨 회복하지 않는다. 이동 중에도 최저 에너지 꽃을 다시 선택한다. 기존 시듦 SVG의 100/66/33 상태를 실제 에너지에 연결한다. 수치는 사용자 미지정 임시 밸런스이며 `src/relic-collection.js`의 tuning에서 조정한다.
- 기존 기본 카드 비교의 고정 보석·하트는 아트 확인용이며, `?attack=0` 비전투 및 `?combat=1` 레거시 실험은 기존 동작을 유지한다. 꽃 소멸, 패배, 슬롯 구매 및 실제 장착 효과는 범위 밖.
- 검증: 모델 1,655개 검사 통과, 45개 순찰 경로 전장 좌표 140,400개 표본에서 획득 가능(보정 1개 포함). 두 해상도 브라우저 통합 검사는 CI 결과 확인 필요.

> **devel 현행 꽃 UI:** 기본 어두운 테마에서 정원 점유/인접 후보 및 꽃 카드는 내부 투명, 1 논리 px 두께의 5px 길이 꺾쇠(공유 모서리 포함)를 사용한다. 꽃 꺾쇠 기본 graphite #3B3A44 (일반 카드·슬롯은 slate #535361 유지), 꽃 드래그/호버 growth #84A83E. 꽃 아이콘, 크기/히트 영역, 드래그·배치·순찰 판정 유지. 일반 아이템·장착 슬롯·정보창과 밝은 비교 테마(`uitype=1`)는 변경하지 않는다. 이전 꽃밭 실선·꽃 카드 배경 설명은 역사적 규격.

- 기본 새 게임: 적 및 자동 공격 없이 요정 11명, 꽃 6종 만개 카드, 일반 아이템 12종 카드, 보석·하트 2종 바닥 유산을 한 번씩 표시. 위치는 정원과 HUD를 피한 고정 앵커 배치. 꽃·일반 드롭 카드는 기존 주기 1800ms, 최대 4px 상향 부유, 위상차 317ms로 움직인다. 카드 테두리·면·그림·레벨 글자가 함께 움직이며 바닥 타원 그림자는 사용하지 않는다. 드래그 시 부유를 즉시 중단하고 장착 슬롯/고스트는 고정. `?cards=0` 숨김, `?cards=legacy` 이전 카드 비교, `?enemies=1` 또는 `?combat=1` 기존 전투 비교 유지. `?flowerheads=1`은 이전 픽셀 꽃 비교.
- 첨부 SVG_items_1000x1000(1).zip의 15개 벡터 원본을 assets/items에 보존. 경로·변환·원본 색상을 유지하며 assets/palette16/items에 기존 Garden 16 v9 역할색만 교체한 사본 생성. `?svgcolors=original`에서 원색 비교. `scripts/recolor-svg.mjs`는 60종 원본과 사본의 색상 및 기하 일치를 검사한다. 바퀴 외륜은 이전 stone(#706975)으로 복원, 스포크는 기존 silver(#96919B), 스포크 사이 8개 공간은 투명 처리한다. 신발 몸체는 red(#FB575F), 내부 음영은 redDark(#D23840), 끈과 밑창은 기존 paper·sand를 유지한다. 스프링클러는 기존 silver·sky 유지. 또한 화분은 clay 몸체·테두리, bark 내부 및 기존 림 경계를 따른 가는 선으로 보정한다. 빗자루 손잡이는 clay로 밝힌다.
- 꽃: 데이지·해바라기·튤립·수국·장미·라벤더의 건강한 만개 SVG(논리 단계 3, 원본 04). 카드 외형 24px, 가시 긴 변 18px. 실제 꽃 배치는 기존 1단계 성장 시작.
- 일반: 신발, 물풍선, 부메랑, 방패, 바퀴, 화분, 종이비행기, 탱탱볼, 끈끈이, 스프링클러, 돌멩이, 빗자루. 카드 외형 32px, 12종 모두 가시 긴 변 24px, 카드 외곽 기준 최소 여백 4px. 빗자루는 원본의 솔 중심과 손잡이 끝을 잇는 축을 오른쪽 위 45° 방향으로 회전한 뒤 투명 경계를 잘라 카드 대각선을 활용한다. 물보라(물웅덩이)는 카드/셀렉트에서 제외하며 물풍선 착지 효과로만 사용한다. 원본 파일 및 sky(#6794D8) 팔레트 사본은 보존. 실제 슬롯 장착 및 교체 UI에서 동일한 SVG 사용. 일반 아이템 기본 레벨 1, 표시 범위 1~3. 우하단 `Lv.1`~`Lv.3` 8px paper(#F4F1E9) 공통 Fusion Pixel 글자, 기존 UI 그림자 색(#0D0D0E) 우하단 1px 오프셋, 블러 0. 별도 상자/외곽선 없이 그림자를 포함한 가시 경계를 카드 외곽에서 오른쪽·아래 각각 2px 안쪽에 맞춘다(1px 테두리와 1px 내부 공백). 드롭·장착·스냅 고스트에 동일 레벨을 표시. 꽃 카드/보석/하트 레벨 표시는 추가하지 않는다. 레벨업 및 레벨별 효과 미구현. 기존 손수레는 임시 픽셀 샘플로 별도 비교에만 유지.
- 바닥 유산: 신규 첨부 gem_1000.svg·heart_1000.svg의 원본과 Garden 16 사본 사용(이전 07 파일 보존). 보석 skyLight(#91B8F7) 12px, 하트 red(#FB575F) 12px(두 유산 모두 투명 여백 제거 후 가시 긴 변 12px, 원본 비율 유지), 카드·외곽선·드래그 없음. 적 사망 후 남는 유산의 시각 시안이며 실제 적 처치, 획득, 회복, 재화 계산은 이번 범위 밖.
- 모든 아이콘은 512px SVG 렌더링에서 투명 여백만 제거하고 원본 비율을 유지한다. 현재 물리 화면 배율에 맞춘 단계적 고품질 다운샘플링으로 출력 크기 텍스처를 생성하고 LINEAR 필터로 표시한다. 리사이즈 시 동일 논리 크기에서 재생성한다. 픽셀 샘플로 변환하지 않음. 불투명 벡터 면 색상은 기존 16색, 안티앨리어싱 경계 혼합색 허용. 일반 아이템 문구와 수치는 아래의 UI 시안 데이터에 한정한다. 실제 효과·전투 연동은 미구현.
- 검증: 첨부 SVG 15종 원본과 정규화한 태그 내용의 일치 확인. `tests/restore-card-preview.mjs`에서 두 해상도의 20종 렌더링, 가시 크기, 적 요청 없음, 꽃 배치/드래그, 장착/교체, 일시정지 및 재시작을 검증하도록 구성. 실행 결과는 Actions 참조.

## 보석 HUD

- 상단 보석 수량 왼쪽 가시 긴 변 14px, 하단 잠김 슬롯 999 위 8px. 둘 다 바닥 보석과 같은 gem_1000.svg / skyLight(#91B8F7) 사용. 점선 예약 도형 제거, 그림자 없음, 수량·비용·활성 상태 유지. 기존 열/슬롯 크기는 유지. 25% 알파 가시 경계를 물리 픽셀에 맞춰 상단 수치 앞 5px 및 하단 수치 위 3px 공백, 상단 중앙 Y=15 및 슬롯 수평 중앙 정렬. 모든 게임 모드에서 로드하며 카드 비활성 모드에서도 표시.

| 물풍선 | 떨어진 지점에서 터지며 주변 적들에게 피해를 줍니다. | 초당 피해량 +24 |
| 부메랑 | 날아갔다 돌아오며 경로상의 적들을 공격합니다. | 초당 피해량 +18 |

- 기본 UI 능력치: 우하단 왼쪽부터 초당 피해량 20, 방어력 12, 이동 속도 100. 좌하단은 비워 두고 중앙 슬롯 및 기존 70px 열·8px 글꼴을 유지한다. 최대 체력·행운·획득 범위는 UI 스탯 및 합산에서 제외한다. 이전 카드 비교의 네잎클로버·자석은 설명만 유지하며 수치 효과 없음, 보호 비료는 방어력 +6만 유지한다. 드래그 시 증감 미리보기 및 장착·교체 합산에만 사용한다. 요정 실제 이동 속도, 적 감속, 공격·방어 계산에 연동하지 않는다. 끈끈이는 하단 능력치에 대응하지 않는 적 감속 효과이므로 `stats`를 비워 초당 피해량 및 플레이어 이동 속도에 합산하지 않는다. 툴팁 전용 `tooltipEffect`는 `적 이동 속도 -30%`로 표시하고 기존 끈끈이를 교체할 때는 `적 이동 속도 -30% 효과 제거`로 표시한다. 다른 아이템에서 끈끈이로 교체하는 경우 제거되는 기존 능력치만 하단에 반영한다. 실제 감속 미구현.
- 검증: 실제 소스 데이터 12종 및 기존 합산 함수로 장착·교체 수치 확인. 이전 29px 빗자루 확대 시안은 24px 공통 크기로 대체. 45° 축은 유지. 이전 바퀴·신발 색상 보정 및 스프링클러 불변은 Chromium 독립 렌더링으로 확인했다. 바퀴 외륜 원복은 변경 전 SVG와 내용 일치 및 생성 규칙 검사 통과; 전체 브라우저 회귀는 미실행. 배포 SHA를 SVG 요청 URL에 포함하도록 수정해 이전 이미지 캐시를 분리한다. 전체 게임 브라우저 테스트는 CI 검증 대상으로 유지한다.
