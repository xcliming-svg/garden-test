# 전체 SVG 아이템 카드 및 바닥 유산 — devel 비교

- 기본 새 게임: 적 및 자동 공격 없이 요정 11명, 꽃 6종 만개 카드, 일반 아이템 12종 카드, 보석·하트 2종 바닥 유산을 한 번씩 표시. 위치는 정원과 HUD를 피한 고정 테스트 배치. `?cards=0` 숨김, `?cards=legacy` 이전 카드 비교, `?enemies=1` 또는 `?combat=1` 기존 전투 비교 유지. `?flowerheads=1`은 이전 픽셀 꽃 비교.
- 첨부 SVG_items_1000x1000(1).zip의 15개 벡터 원본을 assets/items에 보존. 경로·변환·원본 색상을 유지하며 assets/palette16/items에 기존 Garden 16 v9 역할색만 교체한 사본 생성. `?svgcolors=original`에서 원색 비교. `scripts/recolor-svg.mjs`는 58종 원본과 사본의 색상 및 기하 일치를 검사한다. 바퀴 외륜은 bark(#4E352E), 스포크는 기존 silver(#96919B), 스포크 사이 8개 공간은 투명 처리한다. 신발 몸체는 red(#FB575F), 내부 음영은 redDark(#D23840), 끈과 밑창은 기존 paper·sand를 유지한다. 스프링클러는 기존 silver·sky 유지. 또한 화분은 clay 몸체·테두리, bark 내부 및 기존 림 경계를 따른 가는 선으로 보정한다. 빗자루 손잡이는 clay로 밝힌다.
- 꽃: 데이지·해바라기·튤립·수국·장미·라벤더의 건강한 만개 SVG(논리 단계 3, 원본 04). 카드 외형 24px, 가시 긴 변 18px. 실제 꽃 배치는 기존 1단계 성장 시작.
- 일반: 신발, 물풍선, 부메랑, 방패, 바퀴, 화분, 종이비행기, 탱탱볼, 끈끈이, 스프링클러, 돌멩이, 빗자루. 카드 외형 32px, 12종 모두 가시 긴 변 24px, 카드 외곽 기준 최소 여백 4px. 빗자루는 원본의 솔 중심과 손잡이 끝을 잇는 축을 오른쪽 위 45° 방향으로 회전한 뒤 투명 경계를 잘라 카드 대각선을 활용한다. 물보라(물웅덩이)는 미리보기에서 제외하고 원본 파일은 보존. 실제 슬롯 장착 및 교체 UI에서 동일한 SVG 사용. 기존 손수레는 임시 픽셀 샘플로 별도 비교에만 유지.
- 바닥 유산: 보석 12px, 하트 14px, 카드·외곽선·드래그 없음. 적 사망 후 남는 유산의 시각 시안이며 실제 적 처치, 획득, 회복, 재화 계산은 이번 범위 밖.
- 모든 아이콘은 512px SVG 렌더링에서 투명 여백만 제거하고 원본 비율을 유지한다. 현재 물리 화면 배율에 맞춘 단계적 고품질 다운샘플링으로 출력 크기 텍스처를 생성하고 LINEAR 필터로 표시한다. 리사이즈 시 동일 논리 크기에서 재생성한다. 픽셀 샘플로 변환하지 않음. 불투명 벡터 면 색상은 기존 16색, 안티앨리어싱 경계 혼합색 허용. 일반 아이템 문구와 수치는 아래의 UI 시안 데이터에 한정한다. 실제 효과·전투 연동은 미구현.
- 검증: 첨부 SVG 15종 원본과 정규화한 태그 내용의 일치 확인. `tests/restore-card-preview.mjs`에서 두 해상도의 20종 렌더링, 가시 크기, 적 요청 없음, 꽃 배치/드래그, 장착/교체, 일시정지 및 재시작을 검증하도록 구성. 실행 결과는 Actions 참조.

- 기본 UI 능력치: 이동 속도 100, 방어력 12, 초당 피해량 20. 드래그 시 증감 미리보기 및 장착·교체 합산에만 사용한다. 요정 실제 이동 속도, 적 감속, 공격·방어 계산에 연동하지 않는다. 끈끈이의 초당 피해량 +8은 요청에 따른 임시 표시 수치로 실제 피해 설계를 뜻하지 않는다.
- 검증: 실제 소스 데이터 12종 및 기존 합산 함수로 장착·교체 수치 확인. 이전 29px 빗자루 확대 시안은 24px 공통 크기로 대체. 45° 축은 유지. 바퀴·신발 색상 보정 및 스프링클러 불변은 파생 SVG 해시와 Chromium 독립 렌더링(1/1.33/2배)에서 확인했다. 배포 SHA를 SVG 요청 URL에 포함하도록 수정해 이전 이미지 캐시를 분리한다. 전체 게임 브라우저 테스트는 CI 검증 대상으로 유지한다.
