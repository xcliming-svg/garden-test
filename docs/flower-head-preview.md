# 꽃 머리 크기 비교 — feature/flower-head-preview

> **devel 전투 테스트 (main 6f161a1 기준 별도 실험):** 아래 기존 정적 비교 화면의 이력을 보존하며, devel에서는 다음 사양으로 대체한다.
> - 10×10 꽃·정원 좌표·크기·HUD 유지. 정원 내부 그리드와 외부 보더를 모두 제거하고 #161619 단일 면만 그린다.
> - 수호자 본체 44px(기존 크기 URL 유지), 원본 비율 유지 및 1px slate #51516B 외곽선 추가(기본 전체 높이 46px). 애벌레 32×18px 유지, 외곽선만 slate로 변경해 검은 전장에서 보이게 한다. 꽃은 기존 ink 1px 외곽선 유지.
> - 수호자 순찰 72→24논리 px/s. 애벌레 기본 38px/s(±12%), 네 방향 전장 밖에서 차례로 출현하여 정원 내부의 분산 목표로 이동. 도착 후 2.5초 체류하고 사라지며 처치 수에 포함하지 않는다.
> - 출현: 초당 0.8마리부터 15초마다 0.65마리/s 증가, 최대 6마리/s 및 동시 160마리. 고정 시드의 테스트 난수로 반복 비교 가능.
> - 자동 공격: 첫 0.65초, 이후 1.7초마다 수호자 몸 중심에서 고정 원점의 원형 금색 충격파가 180px/s로 최대 반경 160px까지 확장. 파동 접촉(중심 기준 10px 허용)에 적 1회 처치, 작은 소멸 링과 실제 처치 수 HUD 연동.
> - 전장 경계로 적과 효과를 마스킹, 일시정지 시 시간·순찰·적·파동 정지, 새 게임에서 상태 초기화. 시간 및 처치 수만 실제 집계하며 이동 속도 표시 24. 나머지 HUD 능력치·정원 완성도는 임시 값, 꽃 피해·패배·보상·장착·레벨업은 미구현. 이 수치는 테스트용으로 확정 밸런스가 아니다.
> - 코드: src/combat-preview.js(독립 테스트 시뮬레이션/표시), src/flower-head-preview.js(아트/정원), src/game-layout.js(HUD). 기존 정적 비교 검사 대신 tests/combat-preview.mjs를 사용한다.
