# 꽃 머리 크기 비교 — feature/flower-head-preview

- 기준: main c811115. 사용자 요청에 따라 devel에 병합하여 Pages 비교 화면으로 제공한다. main은 변경하지 않는다.
- 960×540 논리 해상도, 기존 HUD·도안·슬롯 및 Garden 16 유지.
- 정원 기본 외형 24px, 내부 22px, 공유선 1px, 피치 23px. 기존 10×10 영역 100칸에 네 꽃 머리를 반복 배치한다. 최대 외형 231px 유지.
- 3(3).svg 데이지, 4(4).svg 튤립(p01~p03만), 5(2).svg 해바라기, 6(1).svg 파란 꽃의 꽃 머리 파츠만 사용. 줄기·잎(tulip-p04~06) 제외. 1(4).svg 사람의 전체 파츠 사용. 원본 SVG는 변경하지 않고 사용자가 제공한 원본의 파츠에서 표시용 픽셀 데이터만 생성한다.
- 알파 외접 범위를 잘라 원래 가로세로 비율을 유지하고 최대 변을 22px(대형 비교 32px)에 맞춘다. 고해상도 래스터에서 픽셀 면적 우세색, 50% 알파 기준 이진화 및 Garden 16 역할색 적용. 수호자는 24px 원본 크기 틀, 기존 순찰 속도 72px/s 유지. 원본 SVG의 색을 그대로 복사한 것이 아니다.
- 기본 FHD에서는 타일 외형 48px, 꽃 머리와 외곽선 최대 변 44px. 꽃 색상 면은 최대 20논리 px, 1논리 px(2 FHD px) ink #0D0D0D 외곽선을 셀 내부에 추가한다. 원본 데이터는 보존하고 최근접 샘플링을 사용한다. 내부 그리드 선과 교차점은 모두 정원 면 #161619로 채우고 외부 1px 프레임만 유지한다. 도안·HUD·슬롯은 기존 표시용 UI 그대로, 필드 적/보석/아이템/꽃 드롭은 생성하지 않는다. 꽃 배치·아이템 장착 데모는 이 비교 화면에서 동작하지 않는다.
- 수호자 크기 비교: 기본 32논리 px(64 FHD px), `?person=28`(56 FHD px), `?person=24`(48 FHD px). 24px 원본 텍스처의 최근접 확대, 종횡비와 기존 순찰 경로·속도 유지. 32px은 비교용 기본값이며 사용자 확정 규격은 아니다.
- 현행 변경 검증: 코드 1076a6c의 [Chromium 11/11 구성 통과](https://github.com/xcliming-svg/garden-test/actions/runs/43522146911). FHD 실제 꽃 외곽선 및 내부 공유선 색상 검사, 사람 24/28/32px 비교, 기존 해상도·DPR·순찰·ESC 검사와 원본 래스터 해시 일치. 다른 브라우저는 미검증.
- 최초 실험 검증: 코드 a7738d0의 [Chromium 전용 검사 9/9 통과](https://github.com/xcliming-svg/garden-test/actions/runs/43521350619). 9개 원본 변환 래스터 해시 일치, 5개 해상도·DPR2·대형 정원/24·36px 슬롯 비교에서 100개 꽃과 수호자만 생성, 팔레트/알파·위치·순찰·ESC·런타임 검사 통과.
