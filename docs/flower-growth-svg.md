# 꽃 성장·시듦 SVG — devel 비교

> **devel 선택 비교:** `flowerTone=1` 꽃 시각 강조 완화(채도 65%, 명도 85%, 대비 85%), `enemyOutline=1` 적 실루엣 외곽선(기본 어두운 ink, 1 논리 px). 두 효과는 기본 OFF 및 기존 `clarity=1`과 독립. 꽃의 원본/HP 변형을 보존하며 현재 단계의 표시용 텍스처만 변환한다. [규격](./enemy-preview.md#꽃-시각-강조-완화-및-적-외곽선).

> **main/devel Garden 16 v9:** [공통 색상 가이드](./ui-color-guide.md)가 최신 색상 규격이다. 16개 기본색 및 UI 파생 음영을 적용하고, SVG 원본은 보존하며 `?svgcolors=original`에서 원본 색상을 표시한다. 아래 이전 팔레트 수치와 색상 관련 기록은 역사적 기준이다.

- 기반: 현재 devel의 3단계 꽃 성장 실험. 기존 전투·투사체·드롭·순찰·수호자·테마를 유지한다.
- 참고 자료: 사용자 제공 `flower-growth-damage-full(1).zip`의 JS/HTML/PNG (2026-11-16 확인). 참고 구현은 연속 역변환, 줄기 기울기, 잎의 수축과 처짐, 건조 색감으로 HP별 외형을 표현한다. 원본 스프라이트 시트 재절단과 256px 출력, 임의 노이즈는 채택하지 않는다.
- 원본 SVG 24개를 `assets/flowers/`에 그대로 보존한다. 원본 2/3/4단계를 새 1/2/3단계로 사용하고 원본 1단계는 로딩하지 않는다. 활성 SVG 18개, 정상 및 피격 텍스처 총 54개. 별도 피격 SVG/PNG 파일을 저장하지 않는다.
- `src/flower-damage.js`는 기존 512×512 정상 SVG 텍스처의 가시 범위를 측정하고, 원본 X500/Y856을 기준으로 상부 줄기의 휘어짐, 좌우 수축 및 바깥쪽 잎·꽃잎의 하향 처짐을 연속 역변환으로 구현한다. 하단 기준점 이하의 위치는 유지한다. 알파를 고려한 bilinear 샘플링과 LINEAR 필터, 점진적인 황변·갈변을 적용한다. 경로 삭제·절단·구멍 생성·저해상도 픽셀화 없음. 정상은 원본 SVG 색상을 표시하며 시듦은 원본 기반 연속 황변·갈변을 유지한다. 16색 복사본 및 시듦 RGB 제한은 명시적 `?svgcolors=palette16` 비교에서만 사용한다. [색상 규격](./ui-color-guide.md).
- 에너지 등급: 67~100 정상, 34~66 부상, 0~33 위험. 테스트 대표 HP는 100/66/33이며 변형 강도 0/.45/.90을 사용해 게임 표시 크기에서도 구별되도록 한다. 실제 적 공격에 의한 HP 계산은 미구현.
- 기본 요정 미리보기는 중앙 2×2 초기 4칸, 기존 combat=1 전투 실험은 6종 초기 중앙 3×2 셀(43,44,45,53,54,55) 유지. 원본의 표시 크기, 정렬, 개별 장미/해바라기 위치 보정, flower/person/personstyle/uitype/full 옵션 유지. `?flowerheads=1`은 이전 네 종류 픽셀 꽃 및 초기 4개 배치. 꽃 카드에는 정상 만개, 심기 고스트는 새 1단계.
- 기존 combatPreview 시뮬레이션 시계를 사용해 개별 꽃의 심은 시각부터 5초 간격으로 55초 순환한다. ESC 일시정지 및 새 게임 초기화 유지.

검증: `tests/flower-growth-svg.mjs`에서 원본 보존·활성 로딩, 54개 텍스처의 안티앨리어싱·높이/면적 감소·하단 정렬, 55초 순환 경계, 꽃 카드/심기/독립 성장/ESC, 기존 전투/HUD를 검사한다. 6종 × 9개 상태 비교 이미지와 실제 게임 화면을 저장한다. 기존 projectile-loot 회귀 검증도 유지한다.
