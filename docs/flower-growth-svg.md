# 꽃 성장·피격 SVG — devel 비교

- 기반: 복구된 devel `ca0e891`를 main에 fast-forward 승격한 동일 소스. 별도 feature/flower-growth-svg-damage에서 작업하며 새 실험은 devel에만 통합한다. 기존 전투·투사체·드롭·순찰·수호자·테마를 유지한다.
- 원본 6종 × 4단계 SVG 24개만 assets/flowers/에 동일 blob으로 보존한다. 피격 SVG 파일은 저장하지 않는다. src/flower-damage.js는 원본 SVG 경로와 변환을 읽고 Canvas Path2D로 그린다. 기존 경로를 생략하거나 연결된 형태의 특정 잎·꽃잎 경계를 벡터로 잘라내어 피격 텍스처 30개를 실행 중 생성한다. 원본 색·좌표 유지, 새 그림이나 픽셀 단위 삭제 없음.
- Phaser 3.90 SVG 로더가 정상 원본을 직접 읽어 512×512 안티앨리어스 텍스처로 렌더링한다. 피격 상태도 동일 해상도에 JavaScript 벡터 그리기로 생성한다. LINEAR 필터 사용. 저해상도 픽셀화, 알파 이진화, 팔레트 양자화, 외곽선 추가 없음. Phaser 화면 자체는 GPU 텍스처 방식이며 실제 SVG 파일은 영구 보존한다.
- 기본 최초 여섯 송이: 데이지·해바라기·튤립 / 수국·장미·라벤더, 3×2 중앙 점유 셀 43,44,45,53,54,55. 원본 X500/Y856 기준, 기존 셀 크기 / .85 표시 프레임으로 최대 폭을 셀 안에 맞춘다. 승인된 개별 장미/해바라기 위치 보정도 유지한다. 기존 flower=12~32, person, personstyle, uitype, full 옵션 유지. `?flowerheads=1`은 이전 네 종류 픽셀 꽃 및 4개 초기 배치.
- 꽃 드롭은 6종 모두 선택 가능, 카드에는 정상 만개 아이콘, 고스트와 심은 꽃은 1단계. 각 꽃의 심은 시각에 따라 독립적인 시각 순환. 기존 combatPreview 시뮬레이션 시계와 동기화하며 ESC에서 멈추고 새 게임에서는 초기화한다.
- 모든 상태가 5초 간격으로 전환된다. 60초마다 반복. HP는 시각 테스트 상태이고 실제 적 공격에 의한 HP 계산은 이번 작업 범위 아님.

피격 형태: 새싹은 떡잎/잎끝 탈락, 성장 중 잎자루 절단 또는 봉오리 갈라짐, 만개는 데이지·해바라기 꽃잎, 튤립 양측 꽃잎, 수국 꽃송이, 장미 겹꽃잎, 라벤더 꽃대 일부가 탈락한다. HP33은 HP66과 동일 손상에 추가 손상을 가한다. HP 표시값과 제거 면적은 일치할 필요가 없다.

검증: tests/flower-growth-svg.mjs에서 원본 SVG 24개 로딩과 54개 텍스처 알파/색 및 손상 진척, 60초 경계, 원점 고정, 실제 꽃 카드 드래그 및 독립 성장, ESC, 기존 전투/HUD를 검증한다. 기존 projectile-loot 테스트는 flowerheads=1로 회귀 검증한다.
