# 하단 슬롯 쌍 정렬 비교 (main 기준 실험)

- 실험 분기: `feature/main-slot-pairs-preview` (main 기준 생성), devel에 비교 기능만 통합. main은 변경하지 않음.
- `/devel/?slotPairs=9`: 36×36px 칸을 두 칸씩 붙인 9쌍. 각 쌍 외형 72×36px.
- `/devel/?slotPairs=10`: 34×34px 칸을 두 칸씩 붙인 10쌍. 각 쌍 외형 68×34px.
- 쌍 안쪽 간격 0px, 중앙 구분선 1px, 쌍 사이 간격 3px. 좌측 시작 10px.
- 우측 상태 열 시작 x=740을 그대로 두며 슬롯 비교 영역은 x=10~740 (730px).
  - 9쌍은 672px 점유, 우측에 58px 여유.
  - 10쌍은 707px 점유, 우측에 23px 여유.
- 첫 쌍 왼쪽 칸에 프로젝트의 돌멩이 SVG 및 Lv.1 표시, 나머지는 빈 슬롯. 실제 장착·교체·구매 슬롯과 연결하지 않는 **보기 전용** 겹침 레이어이며 해당 범위의 클릭은 차단.
- `?slotPairs`가 없거나 다른 값이면 기존 Game 씬, 슬롯 배치, 게임 규칙 및 조작을 변경하지 않음. 기존 무효 비교 파라미터 제거 동작을 유지.
- `src/slot-pairs-demo.js`는 Game의 기존 draw 이후에만 비교 레이어를 그린다. `index.html`은 이 두 비교 파라미터만 실행 URL에 유지한다.
- 브라우저 회귀 검사: `tests/slot-pairs-demo-browser.mjs`. 960×540, 1280×720에서 9쌍, 10쌍, 기본 비교의 영역 침범·화면 요소·JS 오류 확인.

미확정: 실제 장착 슬롯 수 및 규칙 변경, 클릭/드래그 상호작용, 픽셀 단위 선호도 확정. 모두 별도 승인 대상.
