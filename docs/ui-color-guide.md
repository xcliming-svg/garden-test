# Garden 16 — 게임 공통 색상 가이드

> 현행 devel: 기존 참조 화면의 색감과 원본 에셋의 표현을 우선하는 16색 공통 설계. 이전 청회색 16색은 대체된 시안이다.
> 색상 원본: [src/palette.js](../src/palette.js). 좌표·크기는 [현행 UI 규격](./resolution-960x540.md), 간격은 [UI 간격 가이드](./ui-spacing-guide.md)를 참조한다.

## 1. 설계 기준

사용자가 선호한 기존 화면(공통 규격 정리 이후 `613ba9b`, UI 16색 통합 `2062627`)의 전장·HUD·보라회색 표면·제목·테두리 관계를 보존한다. 참고 이미지의 색상을 무조건 복사하는 대신 명도/채도/색온도 관계를 우선한다. 청회색 전면 변경 및 강제 16색 스프라이트 변환은 원래 색감과 세부 표현을 약화했으므로 대체한다.

## 2. 공통 팔레트

`GardenPalette.hex`에 정확히 16개 설계 색을 선언하고 `n`과 `reference.hex/n`은 이 원본의 표현·의미별 별칭만 사용한다. 색을 선정할 때 기존 UI의 단색 면 및 기존 자연 소재 색을 우선한다.

## 3. UI 역할 및 명도 체계

- 전장과 메뉴 배경은 ink, 상하 HUD는 hud로 분리한다. 일반 슬롯·카드·도안·정보창·버튼·팝업 본문은 panel, 제목은 header, 선택 및 호버 면은 slate. 비활성 면과 빈 게이지는 hud. 기존 화면의 저채도 보라회색 표면과 명도 차이를 우선한다. 팝업 본문과 일반 표면이 같은 색을 사용하므로 기존 UI의 더 어두운 팝업 면과는 차이가 있다.
- 외곽 테두리는 stone, 슬롯·그리드 등 밀접한 요소의 기본선은 slate, 주요 행동·선택/호버의 포커스는 silver. 밝은 색을 모든 테두리에 적용하지 않는다. HUD 경계는 panel/slate, 내부 구분은 ink.
- 주요 글자·수치·제목은 paper, 보조 설명과 레이블 및 비활성 비용은 silver. 비활성 상태는 낮은 명도의 면·조작 불가·보조 글자와 함께 구분한다. silver는 기존 회색과 가까운 저채도 연보라를 겸하며 전용 보라색을 별도로 늘리지 않는다.
- 증가·성장·배치 가능은 growth, 감소·위험은 red, 주의는 gold, 청색 자원·물은 sky. 상단 보석 자리의 예약 아이콘은 차분한 silver를 사용한다. 강조는 의미가 있는 상태에만 적용하고 장식적인 색을 임의 추가하지 않는다.
- 성공/실패는 주요 제목과 상태색 테두리로 구분한다. 위험 버튼은 일반 면을 유지하고 포커스 경계로 호버를 표시한다. 색만으로 정보를 전달하지 않는다.

## 4. 신규 객체 제작 원칙

1. **소재와 일반적 인식 우선:** 흰 종이·토끼는 paper/silver, 회색 물체는 중성 단계, 나무·화분·달팽이는 자연 갈색·베이지, 꽃·잎·물은 대표색을 선택한다. 원본과 가장 가까운 색상 역할부터 정한다.
2. **실루엣과 명암 보존:** 실제 목표 크기에서 기본색 하나와 필요한 그림자/하이라이트로 시작한다. 색 수 자체를 줄이는 것보다 형태, 소재, 세부 표현이 중요하다. 흰색과 크림색은 별개 역할이다. 어두운 물체에는 필요한 부분만 중성 밝은색을 사용한다.
3. **색의 재사용:** 신규 UI와 에셋은 공통 16색을 제작 기준으로 사용한다. 유사한 역할에 임의의 새 HEX를 선언하지 않는다. 필요한 색이 없으면 기존의 가까운 소재/명도 색을 먼저 시도하고 원본과 목표 크기 비교로 평가한다. 예를 들어 연보라 소재는 silver를 활용할 수 있으나 원본의 선명한 보라와 같지는 않다.
4. **기존 에셋 원본 보존:** 기존 꽃·달팽이·손수레 샘플은 원본 픽셀과 알파 그대로 렌더링한다. `test-sprites.js`의 선택적 16색 근사 데이터는 색상 비교와 제작 참고용이며 실제 게임에 강제 적용하지 않는다. 기존의 섬세한 청색 음영이나 소재의 톤을 보존하기 위한 명시적 예외이다. 따라서 렌더링되는 게임 전체 RGB가 정확히 16색이라는 의미는 아니다.
5. **예외 관리:** 새 에셋은 16색 기본 제작 기준에서 시작한다. 표현이 부족하다면 승인된 원본 유지 또는 색 확장 필요성을 검토하고 실제 크기 비교·이유를 문서화한다. 디자인 토큰은 16개로 유지하며 승인 없이 색을 늘리거나 전체 에셋을 일괄 변환하지 않는다.

## 5. 대비와 검증

sRGB 명암비(일반 면 #3B3B4E / 제목 면 #44445C): 주요 글자 10.93:1 / 9.43:1, 보조 글자 4.93:1 / 4.26:1, 성장 4.51:1 / 3.89:1, 위험 3.79:1 / 3.27:1, 주의 5.92:1 / 5.11:1. 일반 외곽선 stone과 일반 면의 대비는 1.97:1, 기본 그리드선 slate는 1.43:1이다. 원본의 낮은 대비와 명도 관계를 보존하는 선택으로, 모든 작은 텍스트·경계가 4.5:1 또는 3:1 목표를 충족하는 것은 아니다. 일반 면 위 위험 텍스트와 제목 면의 보조 글자는 추후 가독성 개선 검토 대상이며 다른 역할을 임의로 변경하지 않는다.

UI의 16색 정의 및 별칭, 기존 스프라이트 원본 데이터와 표시 데이터의 동일성, 선택적 16색 근사의 알파·색 범위, 실제 출력 배율별 간격과 조작을 검증한다. 합성·안티앨리어싱·기존 원본 에셋 픽셀은 공통 설계 토큰의 수에 포함하지 않는다. 신규 첨부 객체의 추가 자체는 범위 밖이다. 실제 사용자 가독성 평가와 타 브라우저/OS는 별도 검증한다.
