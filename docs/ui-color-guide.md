# UI 16색 공통 색상 설계

> 상태: 2026-11-13 사용자 제공 UI 참고 이미지 7장 및 향후 게임 에셋 시트 2장을 고려해 선정한 신규 디자인 기준. 현재 게임 코드의 적용 팔레트와 구분한다. 코드 적용 전에는 [현행 UI 규격](./resolution-960x540.md)이 실제 구현의 기준이다. 원본 에셋이나 게임 기능을 변경하는 지시가 아니다.

## 1. 설계 근거

- 참고 UI에서 원하는 것은 색상 HEX 복제가 아니라 명도·채도·색온도 관계다. 주요 단색 면의 실측 예: #302E3A(HSL 250°/12%/20%), #343446(240°/15%/24%), #44445C(240°/15%/31%), #4F4F63(240°/11%/35%). 일상 작업 패널 #324056은 217°/26%/27%로 별도 강조 면의 사례다.
- 새 에셋 시트는 녹색 식물과 곤충, 갈색 동물과 화분·손수레, 황금색 꽃과 도구, 청색 수국·물방울·장비, 분홍색 튤립·빨강 자석, 연보라 나방 및 어두운 까마귀 등 다양한 색 계열을 사용한다. 투명 영역을 제외하고 알파 245 이상 픽셀을 8단계 RGB 구간으로 묶어 주요 색을 확인했다(정확한 원본 팔레트 확정이 아님).
- UI 중성 계열은 HSL 색상각 약 205~210°, 채도 약 10~16%의 청회색을 기본으로 하며 식물과 흙, 꽃, 장비 자체의 색이 주인공이 되도록 한다. UI 색은 물체의 종류가 아니라 정보·상태의 의미로 지정한다.

## 2. 16색 목표 팔레트

| 역할 | HEX | 사용 기준 |
| --- | --- | --- |
| shadow | #000000 | 그림자·오버레이, 투명도 유지 |
| field | #111417 | 전체 화면·전장·메뉴 배경 |
| hud | #1B2025 | 상하 HUD 배경 |
| panel | #272E35 | 일반 팝업 본문·잠김/비활성 면·빈 게이지·HUD 내부 구분 |
| surface | #343D46 | 일반 버튼·슬롯·정원·꽃/아이템 카드·도안/정보창 본문 |
| header | #414D58 | 팝업·도안·정보창 제목 면 |
| raised | #505D68 | 선택·호버 면, 낮은 중요도의 그리드/보조 선 |
| border | #909DA8 | 일반 조작 요소의 식별 경계, 주요 패널·게이지 외곽선 |
| focus | #A6BED0 | 선택·포커스·호버 강조 테두리 |
| text | #F1F2EE | 주요 제목·수치·일반 활성 버튼 |
| secondary | #BEC6CB | 설명·레이블·보조 텍스트 |
| disabled | #9EA9B1 | 비활성·잠김 안내, 비용 |
| positive | #9AD56B | 증가·배치 가능·성공·완성도 채움 |
| negative | #FFA59B | 감소·위험·실패·배치 불가 |
| warning | #E9C36D | 주의·중요 알림(필요할 때만 사용, 예약 포함) |
| resource | #82CDE5 | 보석·자원 관련 강조 |

공통 팔레트는 원본 16개 값 하나씩만 선언하고 역할별 별칭을 연결한다. 다중 역할을 이유로 비슷한 HEX를 새로 만들지 않는다. 기존 원본 스프라이트의 색상이나 Garden 32 에셋 팔레트는 UI 색 제한 범위에 포함하지 않는다. 블렌딩·안티앨리어싱으로 발생하는 합성 픽셀 색도 별도로 집계하지 않는다.

## 3. 역할 및 상태 규칙

- 배경의 명도는 field → hud → panel → surface → header → raised 순으로 상승한다. 팝업 본문과 잠김 면은 같은 panel 값, 일반 UI 표면은 surface 값, 모든 제목 면은 header 값으로 통일한다.
- 일반 조작 가능한 버튼·슬롯·게이지 등에서 외형 식별이 필요한 경계에는 border, 장식적인 구분·도안 내부 공유선에는 raised를 사용한다. 단순 배경 경계에 높은 대비를 일괄 적용하지 않는다.
- 활성 기본: surface + border + text. 주요·선택·호버: raised + focus + text. 비활성: panel + 낮은 강조 경계 + disabled. 긍정/부정 상태는 해당 기능 색과 아이콘·텍스트로 함께 전달하고 색만으로 상태를 구분하지 않는다.
- 주요·보조 텍스트 색은 화면에 따라 임의 변경하지 않는다. 보조 텍스트를 raised 위에 두어 대비가 부족하면 text 역할을 쓰거나 더 어두운 배경을 선택한다. 비활성 글자는 panel/surface 같은 낮은 명도 면에 배치한다.
- green/red/amber/cyan 계열은 각각 긍정/위험/주의/자원으로 사용한다. 경고와 위험은 의미가 다르다. 일반 제목·설명을 장식하기 위해 강조색을 반복 사용하지 않는다.

## 4. 명도·대비 검토

sRGB 상대 휘도를 계산한 명암비(물리 픽셀의 글꼴 래스터 및 사람 대상 가독성 검사와 구분한다).

| 전경 | surface #343D46 | header #414D58 |
| --- | ---: | ---: |
| text | 9.82:1 | 7.69:1 |
| secondary | 6.38:1 | 5.00:1 |
| disabled | 4.61:1 | 3.61:1 |
| positive | 6.36:1 | 4.99:1 |
| negative | 5.84:1 | 4.58:1 |
| warning | 6.57:1 | 5.15:1 |
| resource | 6.21:1 | 4.87:1 |
| border | 3.98:1 | 3.12:1 |

일반 텍스트는 주요 면에서 4.5:1 이상, 기능적 외곽선은 필요한 곳에서 3:1 이상을 설계 목표로 한다. 낮은 대비의 장식 선은 기능적 경계와 구분한다. selected 면의 주요 텍스트 대비 약 6.01:1, focus 대비 약 3.51:1. 보조·비활성 텍스트는 위 상태 배치 규칙을 따른다.

## 5. 에셋 색상 관계

- 에셋의 채도·명도는 종류와 실루엣에 따라 정한다. UI의 색 제한을 이유로 꽃이나 동물·도구를 강제로 재색상화하지 않는다.
- 까마귀 몸통의 대표 색 #3C4454는 surface와 약 1.13:1, 방패의 어두운 외곽 #1C4C74는 약 1.23:1로 구분이 약하다. 실제 픽셀 에셋 제작 시 밝은 외곽 픽셀·부분 하이라이트 또는 배경 대비 조정 등을 검토한다. 모든 에셋에 외곽선을 강제로 추가하는 규격은 아니다.
- 노란 꽃·밝은 동물은 같은 surface에서 각각 대표색 기준 약 5.98:1, 6.69:1로 밝게 구분된다. 녹색 식물의 대표색 #549C34는 약 3.25:1, #6CBC34는 약 4.67:1이다. 작은 실제 크기에서의 판독성은 별도 확인한다.
- 원본 에셋 시트의 해상도·색은 최종 16px/24px 래스터의 가독성을 보장하지 않는다. 원본 보존, 목표 해상도 제작 및 실제 출력 배율 테스트를 구분한다.

## 6. 적용 및 검증

색상 변경 작업에서는 현재 공통 색상 정의를 신규 16색과 역할별 별칭으로 매핑하고, 기존 크기·간격·폰트·조작을 보존한다. 테스트의 기존 팔레트 기대값을 새 기준에 맞춰 검증하고 5개 해상도, 5개 언어, 메뉴·팝업, 전장, 정보창, 드래그·선택, DPR 및 비16:9 조건의 실제 브라우저 회귀를 수행한다. 현재 문서는 디자인 설계만 기록하며 실행 코드 변경이나 브라우저 검사 완료를 의미하지 않는다.
