## UI 파생색

UI는 기존 어두운 보라회색 화면과 명도 관계를 유지한다. `shade`는 원색 RGB에 계수를 곱하고 `mix`는 두 원색을 채널별로 혼합하여 반올림한다. `stone`과 `sky` 12% 혼합값을 중성 UI 음영 기준으로 사용한다.

## devel 외곽선 비교 및 지형 확정 (2026-11-18)

- 돌담 표시 없음, 요정 전면, 어두운 잔디(bgtype=6), 투명 점선 꽃밭을 기본으로 고정한다. 직전 `pebbles`, `gardenfill`, `bgtype=7`, `occlusion` 비교는 제거했다. 기존 승인된 0~6 배경 및 uitype=1과 이전 기능 검사 옵션은 보존한다.
- 요정만 기본 stone #706975, 1 논리 px, 군집 시 paper #F4F1E9로 전역 디졸브. 적 외곽선 없음. 중간색은 두 승인 색의 렌더링 보간이며 새 팔레트 색이 아니다. 명시 outlineColor의 16색 정적 비교 및 outlineWidth, outline=0 유지. [규격](./fairy-patrol.md).

## 적용 및 검증

- 42개 승인 비교 SVG(꽃 24·요정/눈/눈물 4·적 12·돌 2)와 이전 애벌레 비교 SVG 1개를 별도 생성한다. 원본 SVG는 그대로 보존한다. `node scripts/recolor-svg.mjs --write`로 재생성, 옵션 없이 원본 색면 순서·복사본·경로·16색을 검증한다.
- 요정과 적은 같은 눈 아틀라스를 사용한다. 적의 승인된 색면을 다시 최근접색으로 양자화하지 않는다. 시듦은 기존 JS 변형과 팔레트 색 매핑을 사용하며 원본 비교 모드는 연속 색을 유지한다.
- v9의 균형은 원본 가시 색면 면적·OKLab 명도/채도/색상각 및 인접 대비를 반복 비교해 정했다. 사용자가 확정한 재질 배색을 원본 색차보다 우선한다. 마지막 고양이·참새 변경도 반영했다. UI와 에셋 크기/동작·기존 씬 구조는 변경하지 않는다.
- 신규 장비 SVG 및 실제 전투 판정은 이번 범위가 아니다. 화면의 모든 RGB가 16개인 것은 아니며 UI 파생색, 원본 비교, 밝은 비교 테마 및 합성색은 예외이다.

이전 16색 실험 및 참조 UI 색은 Git 이력과 [변경 이력](./changes.md)에 보존한다.
