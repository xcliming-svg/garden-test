이전 #454450은 slate, #B8B4B7은 silver(작은 팝업 설명은 paper), #F89596은 red, #FFFFFF 레벨은 paper, #0D0D0D 로딩은 ink로 통합한다. 기본 카드 배경 및 하늘색 강조는 유지한다. 빈 슬롯은 charcoal, 장착된 카드는 graphite. 기존 크기, 위치, 글자 크기, 레벨 인셋 및 입력을 유지한다. red/graphite 대비 약 3.53:1로 기존 밝은 위험 글자보다 낮으므로 8~10px 표시 가독성에는 제약이 있다. paper/graphite 9.92:1, silver/charcoal 5.86:1, skyLight/graphite 5.55:1.

`uitype=1` 비교 테마와 그 밝은 지형도 기존 16색 역할로 치환하되 옵션 및 동작은 유지한다. 전장 배경의 기존 절차적 잔디 음영, 비교 패턴, 반투명 합성, 요정 외곽선 디졸브, 안티앨리어싱은 렌더링 결과이며 고정 UI/에셋 원색 팔레트의 추가 색이 아니다. 내부 흰색 마스크는 표시색이 아니므로 유지한다. `svgcolors=original`은 원본 비교 예외이다.

## 적용 및 검증

- 42개 승인 비교 SVG(꽃 24·요정/눈/눈물 4·적 12·돌 2)와 이전 애벌레 비교 SVG 1개를 별도 생성한다. 원본 SVG는 그대로 보존한다. `node scripts/recolor-svg.mjs --write`로 재생성, 옵션 없이 원본 색면 순서·복사본·경로·16색을 검증한다.
- 요정과 적은 같은 눈 아틀라스를 사용한다. 적의 승인된 색면을 다시 최근접색으로 양자화하지 않는다. 시듦은 기존 JS 변형과 팔레트 색 매핑을 사용하며 원본 비교 모드는 연속 색을 유지한다.
- 기존 16개 재질색(v9)의 균형은 원본 가시 색면 면적·OKLab 명도/채도/색상각 및 인접 대비를 반복 비교해 정했다. 사용자가 확정한 재질 배색을 원본 색차보다 우선한다. 마지막 고양이·참새 변경도 반영했다. UI와 에셋 크기/동작·기존 씬 구조는 변경하지 않는다.
- 신규 장비 SVG 및 실제 전투 판정은 이번 범위가 아니다. 모든 고정 UI 역할은 20색에 속하며, 화면의 모든 RGB가 20개인 것은 아니다. 원본 비교, 절차적 음영 및 합성색은 예외이다.

이전 16색 실험 및 참조 UI 색은 Git 이력과 [변경 이력](./changes.md)에 보존한다.
