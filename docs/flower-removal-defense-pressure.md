## 꽃
- 올바른 종류/틀린 종류 모두 만개 전 도안은 성장 중으로 표시. 만개 후 종류가 다르면 도안 기존 붉은 배경과 정원의 해당 꽃 우하단에 Lv.1 라벨과 유사한 7×9px 불투명 검정 바탕 흰색 ! 표시. 빨간 꽃에서도 동일한 대비를 확보. 제거하면 라벨도 사라지고 도안 미배치.
- 모든 살아 있는 꽃을 마우스 좌클릭으로 같은 칸에서 3초 연속 누르면 제거. 기존 녹색 팔레트, 1px 실선 정사각형 전체 둘레가 끝에서부터 역방향으로 줄어들며 0이면 꽃 제거. 남은 둘레는 남은 시간에 비례. 중간 해제, 칸 이탈, 게임 밖, 일시정지, 적에 의한 꽃 소멸 시 취소. 누르는 중 아이템/꽃 카드 드래그, 슬롯 구매, 도안 접기/펴기 제한. 게임·공격·성장·카드 수명은 계속 진행. 꽃 교체는 직접 덮어쓰기를 금지하고 제거 후 기존 연결 배치 규칙으로 다시 심도록 함. 마지막 꽃 제거 시 기존 실패 조건.
- 3초는 임시 조정값, 꽃 성장 시간/도안 종류/인접 제약/카드 공급 변경 없음.
