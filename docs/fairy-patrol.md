# 요정 11명 순찰 — devel

> **이전 카드 복원 비교 (`?cards=legacy`):** 꽃 카드 3개·아이템 카드 5개와 요정 11명 순찰을 표시하고 적/자동 공격을 숨긴다. 꽃은 인접 빈 칸에 배치, 아이템은 일반 슬롯에 임시 장착/교체한다. `?enemies=1`은 기존 군집·자동 공격, `?attack=0`은 비전투 군집, `?densitySim=1`은 밀집 비교, `?cards=0`은 카드 없는 순찰이다. `?combat=1` 기존 전투 유지. 실제 아이템 효과·드롭·보상 아님.

- 요정 11명만 외곽선: 기본 stone #706975, 1 논리 px. 모든 요정이 하나의 밀집 상태를 공유한다. 적은 외곽선 없음. 전장 내 요정 가시 외접 범위에서 32px 이내인 적을 중복 없이 세어 40마리 이상 2.5초 유지 시 paper #F4F1E9로, 22마리 이하 1.5초 유지 시 stone으로 전환한다. 4초/3초 smoothstep RGB 디졸브, 중간 상태에서도 알파 일정. 전환 중에도 반대 조건을 검사하며 현재 보간색에서 역방향으로 재시작한다. 23~39마리는 현재 목표를 유지한다. 명시적 outlineColor는 정적 비교( outlineMode=adaptive로 강제 가능), outlineWidth=0.5~1.5, outline=0 유지. densitySim=1은 저밀도→200마리 목표→자연 해소 시뮬레이션. combat=1 제외.

> **devel 자동 공격 비교:** 기본 실행에 새싹 요정 5발 빨강·물 요정 2발 노랑 자동 발사 및 적 피격/처치가 추가됐다. `?attack=0`은 이전 비전투 군집 비교, 요정 전면은 기본 고정, `?full=1`은 100칸으로 조합 가능하다. [공격 규격](./enemy-preview.md). 꽃 피해·실제 웨이브·보상 미구현.

> **main/devel Garden 16 v9:** [공통 색상 가이드](./ui-color-guide.md)가 최신 색상 규격이다. 16개 기본색 및 UI 파생 음영을 적용하고, SVG 원본은 보존하며 `?svgcolors=original`에서 원본 색상을 표시한다. 아래 이전 팔레트 수치와 색상 관련 기록은 역사적 기준이다.

> 12종 적이 기본 속도로 무작위 등장하여 실제 꽃까지 진입하고 공격한다. devel 군집 비교에서는 동시 1→200마리(120초), 적 긴 변 24~40px. 꽃과 요정 크기는 변경하지 않는다. 순찰/꽃 성장과 실제 전투 미구현 범위는 유지한다. [적 동물 규격](./enemy-preview.md).

- 기본 실행 화면은 사용자 제공 `fairy_game_assets.zip` (Fairy Game Assets v1, 2026-11-16)의 정원 요정(주인공) 1명과 물 요정 10명이다.
- 원본 `assets/fairies/{garden,water,eyes,tears}.svg` 및 `manifest.json` 보존. 원본 1000×1000 몸체, 1792×256 눈 시트 7종 및 256×256 눈물 시트. 첨부 JS/HTML/PNG를 게임에 직접 이식하지 않는다. Phaser 3.90 로더로 512×512 몸체와 눈 SVG를 읽고 manifest의 좌우 소스/목적지 좌표로 normal/closed/dizzy/happy 합성 텍스처를 만든다. LINEAR 필터, 원본 비율 유지. 기본 모드는 원본 SVG 색상을 사용하며 기본 v9 모드에서 16색 실험을 비교한다. [색상 규격](./ui-color-guide.md). 기존 눈물 SVG를 좌우 눈별로 분리하고 각 요정의 원본 눈 중심과 배율로 배치한다. 추후 전투/결과 연동용 `setState(state)` API(셀렉트 제거): 평상시(normal/closed 독립 깜빡임), 피격(dizzy X X), 승리(happy 웃는 눈, 순찰 정지, 최대 2.5px 비례 점프 2.2Hz), 패배(closed 눈, 순찰 정지, 최대 ±0.9px 비례 좌우 흔들림 2Hz, 눈마다 두 방울이 반복 낙하). 승패 상태는 순찰 거리·시뮬레이션 시계 및 적 이동을 멈추고 감정 애니메이션만 갱신한다. 평상시 복귀로 재개. 실제 HP/승패 판정과 연결하지 않은 비교용 상태이다.
- 발끝 원점 (500,858), 주인공의 실제 높이 기본 40 논리 px, `person=24~56` 유지. 물 요정은 같은 원본 배율(502/716, 약 70.1%)로 기본 약 28px 높이. 각 요정은 별도 sprite로 이동한다. 정원/확장 후보 외접 사각형에서 최대 요정 가시 외곽까지 5px 이상의 간격을 확보하며 기본 40px/s·최대 80px/s의 이동 속도를 사용한다. 기본 실행은 40px/s. 최대 80px/s 및 `setSpeedRank(0/5)` API는 추후 강화용으로 보존한다. 정원은 기본 4칸, `?full=1`로 100칸 비교 가능하며 셀렉트는 제거한다. 11명은 같은 속도와 간격을 유지하고, 변경 순간의 순찰 위치는 보존한다. 기존 24px/s는 이전 모션 비교값이다. [속도 근거 및 적 속도](./movement-speed.md). 11명이 동일 방향으로 균등한 거리 간격을 유지하고, 작은 정원에서는 겹침을 줄이기 위해 경로 좌우 폭을 확장한다(최소 호 길이 간격 = 주인공 높이 ×1.2+4).
- 모든 요정은 시작 시 기본 눈, 각각 독립적인 시드 기반 깜빡임(120~180ms, 이후 2.4~4.9초 간격) 사용. 완화된 상하 발걸음(주인공 0~0.5px, 물 요정 비례)과 ±1.25° 좌우 기울기, 이동 방향 최대 0.5° 기울기, 좌우 반전. 흔들림 주파수 1.6Hz(기존 2.3Hz). 향후 속도 강화는 이동 거리에만 적용하며 기존 걷기 주파수·흔들림·눈 깜빡임은 유지한다. 상하 이동에서는 정면 원본을 유지하고 별도 후면/측면을 그리지 않는다. 걷기 애니메이션은 원본 경로 및 색을 변형하지 않는다.
- 기본 모드에서는 애벌레, 공 발사·피격 파티클, 전투 드롭 및 전투 모델을 생성하지 않는다. 기존 HUD·슬롯·정원·꽃 성장/시듦 55초 순환·배율·테마는 유지한다. 전투와 꽃 심기/장착 드롭의 기존 테스트는 `?combat=1`을 명시할 때만 실행(이전 픽셀 꽃/수호자 조합은 `?combat=1&flowerheads=1`). `personstyle`은 이전 수호자 전용이다. 물주기, 요정별 전투/충돌/길찾기는 미구현.
- 돌담 표시는 제거했다. `pebble-boundary.js`의 기존 순찰/외곽 계산 및 원본 돌 SVG는 보존한다. 적 경로, 이동·기존 크기 및 HUD 맞춤 축소는 변경하지 않는다.
- 게임 씬 시간으로 순찰/깜빡임/꽃 성장 동기화. ESC에서 모두 중단되며 새 게임에서 초기화한다.
- 검증: `tests/fairy-patrol.mjs`에서 원본 SHA-256(줄바꿈 정규화), 실제 눈 텍스처 차이/AA, 1+10 수량·크기·발끝 원점, 4방향 이동, 비동기 깜빡임, 걷기 움직임의 최대 각도(±1.75°)와 높이별 최대 상하 폭(기본 주인공 0.5px), 정원 바깥 순찰, 실제 SVG 알파 외곽 기준 양쪽 5px 간격(0.2px 래스터 오차), 돌 미표시/기존 외곽 계산 및 HUD 경계, 전투 없음, 일시정지, 기존 꽃을 확인한다. 기본/밝은 테마/완성 대형 정원/작은 정원 4개 환경. 이전 꽃·전투 테스트는 명시적 combat=1로 회귀 검증한다.
