- 이전에 제거한 색상 type=1,2와는 다른 전장 확대 비교용 URL이다. type=3~10 및 그 밖의 값은 기본 화면이다.
- 960×540 논리 화면에서 전장(상단 32px, 하단 40px 제외)의 중심 (480,266)을 기준으로 전장 객체의 좌표와 크기를 균일하게 확대한다. 정원·꽃·동물·수호자·필드 드롭/보석이 대상이다. 화면 밖으로 나간 전장 객체는 잘리고 HUD/도안은 항상 그 위에 그려진다. 전체 화면 카메라 및 물리 출력 배율은 기존과 같다.
- 실제 객체 크기·정원 점유 좌표·순찰 속도·애니메이션 프레임 수/FPS·색·원본 SVG는 변경하지 않는다. 정원 바닥은 확대된 화면 픽셀 경계로 직접 래스터화한다.
- 정원 드래그 목적지는 역변환한 전장 좌표로 판정하며 고스트도 전장 배율을 사용한다. 필드 카드 호버 영역은 표시 크기에 맞춘다. 아이템 드래그 중에는 고정 UI 슬롯 크기로 전환하고 취소 시 전장 배율로 복구한다. 정보창은 UI 크기를 유지한다.
- 확대 시 원래 앵커가 화면 밖 또는 도안 밑으로 나갈 수 있어, 1.5×는 아이템 앵커 1개, 2×는 꽃 3개·아이템 2개·동물 2개를 미리보기용으로 이동한다. 보이는 앵커에 동물 9종 모두가 포함되도록 배정하며 수량 62개는 유지한다. 화면 밖/도안 뒤 드롭 카드는 숨겨 입력을 방지한다. 실제 스폰 정책 변경이 아니다.
- 코드: src/game-layout.js의 fieldZoom, fieldPoint, fieldWorld 및 world-only 객체 배치. 기본 URL은 기존 좌표/크기/색상 유지.
