# 기본 플레이 — 성장 및 시간대별 웨이브
2026-11-19. [조사 근거](./survivor-progression-research.md) 후속 승인 적용. 수치는 임시 밸런스이며 실제 플레이 경험에 따라 조정한다. 기존 lab.html 비교는 변경하지 않는다.

## 드롭과 성장
- 적 처치 1회당 하나: 기본 보석 64%, 하트 15%, 꽃 18%, 일반 3%. 일반 카드 생성 최소 30초, 최초 30초 전 일반 당첨은 보석으로 대체. 하트/꽃 당첨은 그대로 유지한다.
- 획득 보석 1개당 XP 1, 구매 잔액과 별도 누적 XP. Lv.1→2 필요 6, 이후 10/14/18… (6+4×(현재 레벨−1)). 초과 XP 보존. 레벨업당 성장 보상 대기 +1.
- 30초 제한을 충족한 다음 보석/일반 당첨 처치에서 대기 보상 1개를 일반 카드로 전환. 첫 일반 카드는 XP가 없더라도 60초 이후 첫 보석/일반 당첨 처치에서 보장. 일반 3% 추첨도 제한 안에서 가능. 따라서 실효 일반 드롭률은 3% 고정이 아니며 성장 보상까지 합해 최대 30초당 1장(초기 30초 제외). 보상 대기 수는 소비된 보석과 무관. 좌하단 Lv./XP/대기 보상 수 표시.
- 일반 후보: 0초 돌멩이·부메랑·신발·방패; 90초 물방울 요정·물풍선; 180초 바퀴·화분; 300초 종이비행기·탱탱볼; 420초 끈끈이·빗자루; 540초 스프링클러. 소유 중 강화 가능 무기 후보를 70% 우대, 그 외 미보유 후보. 후보 소진 시 허용 풀에서 선택. 특정 보상은 유저가 직접 배치해야 적용되며 자동 장착하지 않는다.
- 모든 드롭 일반 카드는 Lv.1. 같은 공격/제어 무기가 장착된 슬롯에 드래그하면 기존 무기 Lv.2→3까지 강화. 이미 Lv.3인 같은 슬롯에는 소비되지 않는다. 다른 슬롯에는 기존처럼 중복 장착 가능. 신발·방패·물방울 요정은 Lv.1 유지. 스냅 고스트/툴팁/기준 DPS/실제 발사 스탯 모두 강화 후 값 사용.
- 꽃 18% 및 도안 필요 꽃 우선(75%), 하트 15%와 손상된 살아 있는 꽃만 회복 규칙, 기존 카드 생성 금지 구역·수명·슬롯 가격·승패 규칙 유지. 별도 상점·레벨업 팝업 없이 전투 중 기존 카드 드래그 흐름 보존.

## 웨이브
`run-rules.js`의 waves가 정확한 기준. 시간(초), 간격, 동시 생존 상한, 한 번에 생성 수, HP 배율, 피해 배율, 신규 적 종류/가중치로 구성. 3분간 애벌레만 생성. 기존 해금 시간 유지, 신규 출현 풀을 구간별 변경하며 처음 출현하는 종은 우선 1회. 구간 전환 시 기존 적은 그대로 생존하고 낮아진 상한까지 자연히 감소할 때까지 신규 생성 중단. 배율은 생성 시 고정, 기존 적 스탯 변경 없음. HP는 기존 공격 유형/종 레벨 기본값에 배율 곱 후 반올림, 꽃 피해는 기존 4/6/8에 배율 곱 후 반올림·방어력 차감, 최소 1. 적/요정 기존 최소 이동 속도 유지.

## 검증
- 순수 모델 15,687개 통과. 기본 확률 1,000개 표본 640/150/180/30, 성장/소비 분리, 첫 보상 보장, 카드 간격, 무기 강화, 웨이브 전체 종/배율/간격/생존 적 유지 및 기존 기능.
- 3분 모델 근사 시험 5개 시드, 초기 돌멩이만, 수동 카드 장착/꽃 확장 없음: 73~75킬, 보석 39~49, 꽃 카드 9~18, 일반 카드 3~4, 최초 일반 카드 32.3~42.1초, 5회 모두 꽃 4개 생존. 실제 UI 플레이와 후반 밸런스의 검증을 대체하지 않는다.
- 브라우저 960×540/1280×720에서 기존 통합 검증 + 실제 포인터 돌멩이 강화 2회와 무기 모델 레벨, 성장 HUD, 보석 소비 후 누적 XP 유지 확인.
