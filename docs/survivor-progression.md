# 기본 플레이 — 카드 공급 및 시간대별 웨이브
2026-11-19. [조사 근거](./survivor-progression-research.md) 후속 요청에 따라 카드 공급과 적 출현만 적용. XP, 레벨업, 무기 강화, 추가 HUD, 상점, 적 체력·피해 배율 변경은 적용하지 않는다. 수치는 임시 밸런스이며 실제 플레이 경험에 따라 조정한다. 기존 lab.html 비교는 변경하지 않는다.

## 드롭
- 적 처치 1회당 하나: 기본 보석 69%, 하트 10%, 꽃 18%, 일반 3%(후속 플레이 의견 반영). 일반 카드 생성 최소 간격 30초. 첫 카드는 추첨 성공 시 생성 가능하며 별도의 강제 보상은 없다. 간격 내 일반 카드 당첨은 보석으로 대체한다. 하트/꽃 당첨은 유지.
- 일반 후보: 0초 돌멩이·부메랑·신발·방패; 90초 물방울 요정·물풍선; 180초 바퀴·화분; 300초 종이비행기·탱탱볼; 420초 끈끈이·빗자루; 540초 스프링클러. 현재 해금 후보에서 균등 추첨.
- 기존 장착/교체/중복 장착·카드 외형/기본 스탯·보석 사용 방식 유지. 경험치나 무기 레벨업은 추가하지 않는다. 꽃 18% 및 도안 필요 꽃 우선(75%), 하트 10%와 손상된 살아 있는 꽃만 회복 규칙, 기존 카드 생성 금지 구역·수명·슬롯 및 승패 기본 규칙 유지(가격·팝업 최신 기준은 playable-run.md).

## 웨이브
`run-rules.js`의 waves가 정확한 기준. 시간(초), 간격, 동시 생존 상한, 한 번에 생성 수, 신규 적 종류/가중치로 구성. 3분간 애벌레만 생성. 기존 해금 시간 유지, 신규 출현 풀을 구간별 변경하며 처음 출현하는 종은 우선 1회. 구간 전환 시 기존 적은 그대로 생존하고 낮아진 상한까지 자연히 감소할 때까지 신규 생성 중단. 체력과 꽃 피해는 기존 무기 밸런스 및 방어력 계산 그대로 유지. 적/요정 기존 최소 이동 속도 유지.
