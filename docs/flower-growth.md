# 꽃 성장·피격 비교 화면 — feature/flower-growth-damage

- 기준: main `6f161a1`. devel은 main의 파일 트리로 동기화하고 이전 실험 커밋 이력은 보존한다. main은 변경하지 않는다.
- 기본 실행: 새 게임에서 데이지, 해바라기, 튤립, 수국, 장미, 라벤더를 왼쪽부터 3열 × 2행으로 배치한다. 기존 10×10 정원 바닥, 수호자 순찰, 정적 애벌레, HUD·슬롯·도안은 유지한다. 이전 100개 꽃 머리 비교는 `?flowerheads=1`에서 확인할 수 있다.
- `assets/flowers/`: 최종 장미 위치 수정본 ZIP의 24개 1000×1000 SVG. CRC32 24/24 일치. 원본 경로·색·비율·좌표를 수정하지 않는다. 표시용 64×64 래스터는 원본 캔버스 전체를 유지하고 알파 128 기준 이진화, NEAREST 필터를 적용한다. 원본 색은 이 비교 화면에 한해 유지한다. 기존 Garden 16 UI 색상은 변경하지 않는다.
- `src/flower-growth.js`: 꽃별 정상 4종, 1~3단계 HP50 및 4단계 HP66/33을 JS로 생성하여 총 54개 표시 텍스처를 사용한다. 원본 실루엣 가장자리에서 불규칙한 픽셀 조각을 제거한다. 낮은 HP는 더 많은 부분을 제거하며 하단 18%를 보존한다. HP 수치와 제거된 면적은 동일한 비율을 의미하지 않는다.
- 6개 꽃은 동시에 심어진 테스트 상태로 시작한다. 각 단계 10초 표시, 40초 경과부터 5초 간격으로 피격 상태를 진행하며 80초에 1단계 정상으로 반복한다. 4단계는 30~40초 동안 정상 표시한다. 별도 심기 입력이나 실제 피해, 사망, 스폰, HP 계산은 이번 범위에 포함하지 않는다.

| 경과 시간(초) | 성장 단계 | 표시 HP |
| --- | --- | --- |
| 0–10 | 1 | 100 |
| 10–20 | 2 | 100 |

| 30–40 | 4 | 100 |
| 40–45 | 4 | 66 |
| 45–50 | 4 | 33 |
| 50–55 | 3 | 100 |

| 70–75 | 1 | 100 |
| 75–80 | 1 | 50 |

ESC 일시정지에서 시간이 멈추며 새 게임 시 초기화한다. 테스트는 `tests/flower-growth.mjs`의 Chromium 검사에서 모든 원본과 피격 텍스처, 시간 경계, 위치, 일시정지 및 기존 UI를 확인한다. 실제 배포 및 검증 결과는 변경 이력에 기록한다.
