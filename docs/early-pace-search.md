# 초반 전투 밀도 최적화 — 탐색 사전 규격

기준 main 06efc7a, 실제 게임 소스 변경 금지. 정사각형/십자/하트 각각 탐색. 기존 적 종류 및 피해/HP, 무기와 슬롯 비용 보존. 첫 270초 웨이브 출현 간격/상한/묶음만 수정하고 이후 행은 유지한다. 꽃·아이템 비율 변경 시 하트 10% 보존, 나머지 보석. 실제 재미/인간 숙련도 검증은 아니다.

사전 규격은 simulation/experiments/early-pace-search.mjs의 protocol에 고정한다. 목표(가설): 기존 첫 30초 동시 적 P50의 2/2.5/3배, 적어도 동시 적 및 처치 1.5배. 완료시간 P50 80–120%, P90 125% 이하, 진행 정체 P90 115% 이하, 첫 장비 P50 65% 이하, 장착 슬롯 P50 1개 이상 증가 및 도안별 5/6/7 이하, 승률 90% 이상 및 대조군 대비 10%p 이내 하락. 첫 장비 없는 실행은 10% 이하, 해당 시간은 종료+1로 벌점. 사용자 승인 수치가 아닌 검증용 가설이며 통과하지 못하면 미확정으로 기록한다.

밀도 18조합×3 seed×60초 → 도안별 상위 2개. 보상 36조합×3 seed → 상위 4개. 주변 세분화(꽃/장비 ±1%p, 간격 ±5초, 출현 간격 ±.25초, 상한 ±1)×6 새 seed → 상위 2개. 독립 16 seed × 초보/일반/숙련 정책 → 각 정책 모든 gate 통과만 유지. 시간 간격 .025초 독립 8 seed. 대조군은 각 단계 동일 시드, 정책, 시간 간격. 모든 후보 및 탈락 사유를 저장한다. 독립 검증에 실패한 후보는 확정하지 않는다. 모델은 fallback geometry이며 브라우저 검증이 별도 필요하다.
