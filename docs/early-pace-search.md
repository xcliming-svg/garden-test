# 초반 전투 밀도 최적화 — 탐색 사전 규격

기준 main 06efc7a, 실제 게임 소스 변경 금지. 정사각형/십자/하트 각각 탐색. 기존 적 종류 및 피해/HP, 무기와 슬롯 비용 보존. 시작 시각 0–270초인 웨이브 6개 행 출현 간격/상한/묶음만 수정하고 이후 행은 유지한다. 꽃·아이템 비율 변경 시 하트 10% 보존, 나머지 보석. 실제 재미/인간 숙련도 검증은 아니다.

사전 규격은 simulation/experiments/early-pace-search.mjs의 protocol에 고정한다. 목표(가설): 기존 첫 30초 동시 적 P50의 2/2.5/3배, 적어도 동시 적 및 처치 1.5배. 완료시간 P50 80–120%, P90 125% 이하, 진행 정체 P90 115% 이하, 첫 장비 P50 65% 이하, 장착 슬롯 P50 1개 이상 증가 및 도안별 5/6/7 이하, 승률 90% 이상 및 대조군 대비 10%p 이내 하락. 첫 장비 없는 실행은 10% 이하, 해당 시간은 종료+1로 벌점. 사용자 승인 수치가 아닌 검증용 가설이며 통과하지 못하면 미확정으로 기록한다.

밀도 18조합×3 seed×60초 → 도안별 상위 2개. 보상 36조합×3 seed → 상위 4개. 주변 세분화(꽃/장비 ±1%p, 간격 ±5초, 출현 간격 ±.25초, 상한 ±1)×6 새 seed → 상위 2개. 독립 16 seed × 초보/일반/숙련 정책 → 각 정책 모든 gate 통과만 유지. 시간 간격 .025초 독립 8 seed. 대조군은 각 단계 동일 시드, 정책, 시간 간격. 모든 후보 및 탈락 사유를 저장한다. 독립 검증에 실패한 후보는 확정하지 않는다. 모델은 fallback geometry이며 브라우저 검증이 별도 필요하다.

## 2차 탐색 사전 규격 (1차 독립 검증 후)
정사각형만 1차 두 후보가 완료시간 하한에서 탈락했다. gate는 변경하지 않는다. 세분화 상위 2개 밀도/장비확률은 유지하고 꽃 10/11/12%, 장비 간격 20/25초를 교차 탐색(12조합, 신규 seed 6101–6108, 초보·일반). 정책별 점수 중 최악 점수 최소화, 상위 2개를 신규 독립 seed 7101–7120의 3정책에서 검사. .025초 민감도는 신규 seed 8101–8108. 이 추가 루프는 1차 결과를 본 뒤 사전 정의한 것이므로 1차 독립 시드를 재사용하지 않는다. 십자/하트는 기존 5101–5108 민감도 규격 유지. 최종 검증은 모두 통과한 후보 중 탐색 순위가 높은 것을 우선하며, 미통과 시 미확정으로 남긴다.

하트는 .025초 검사에서 두 후보 모두 진행 정체 P90 및 장착수 P50 상한 위반. 밀도/묶음 유지, 꽃 9/10/11%, 장비 5/6/7%, 간격 20/30초 18조합×8 신규 seed 9101–9108×초보·일반. 최악 정책 점수 순위 상위 2개를 seed 10101–10120의 3정책으로 독립 검사하고 .025초 신규 seed 11101–11116으로 추가 검사. 원래 gate 유지. 기존 sensitivity는 새 seed와 dt를 함께 변경했으므로 dt 자체의 차이를 분리한 수렴검사는 아니다. 각 결과는 해당 dt/seed의 기준군과 비교한다.

## 3차 확인 사전 규격 — 실제 geometry와 Phaser

기존 모델 선정 이후 다음 gate를 별도 고정한다. 실제 Phaser에서 측정한 geometry를 사용해 미사용 seed 12101–12116, .05초 3정책 및 .025초 일반 정책에서 대조군/선정값을 동일 seed 비교(도안별 128, 합계 384회). 기존 gate를 변경하지 않는다. 같은 seed에서 두 dt를 비교하므로 전 단계의 dt+seed 교차 변경보다 독립적인 시간 간격 점검이 가능하다. 실제 Phaser에서 seed 13101–13103 각각 90초 대조군/후보 실행(도안별 6, 합계 18회). 3개 seed 중앙값 기준 첫 30초 동시 적·처치 및 60초 처치 각각 대조군 1.5배 이상, 후보 패배 없음, 4칸 이상 유지 및 드래그 성공 필수. 실제 브라우저 전체 캠페인의 완료시간/최종 장착 검증은 아직 아니다. 모델 및 브라우저 게이트 결과와 지문을 JSON/CI artifact에 보존한다. 결과를 미리 확정하지 않는다.

```sh
node tests/early-pace-model.mjs
npm install --no-save --package-lock=false playwright@1.51.1 phaser@3.90.0
node tests/early-pace-browser.mjs classic /tmp/pace-classic-reference.json
node tests/early-pace-browser.mjs cross /tmp/pace-cross-reference.json
node tests/early-pace-browser.mjs heart /tmp/pace-heart-reference.json
```

작업 브랜치 feature/early-pace-optimization. 실제 기본 밸런스, main/devel, 이전 군집 연구 브랜치 미변경. 사용자 승인 및 별도 적용 검증 전 배포하지 않는다.
