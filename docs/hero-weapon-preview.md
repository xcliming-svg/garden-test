# 나뭇잎 요정 단독 무기 비교

- 기준: main `5a89bbc`에서 분기한 `feature/hero-weapon-preview`. 기본 새 게임에서만 적용한다. 기존 명시적 `?enemies=1`, `?attack=0`(군집), `?combat=1`, `?cards=legacy`, `?cards=0` 비교를 유지한다.
- 기본 상태는 무기 없음. 기존 나뭇잎 요정 5발·물방울 요정 2발 자동 구슬은 기본 모드에서 생성하지 않는다. 적도 로딩/생성하지 않는다. 1+10 순찰, 꽃·아이템 카드, HUD, 원본 SVG 및 팔레트는 유지한다.
- 전장 우상단 무기 셀렉트(신발·방패 제외)에서 아래 10개를 선택한다. 선택 즉시 기존 이펙트를 제거하고 나뭇잎 요정(index 0, garden)만 1.6초 주기로 자동 발사한다. 선택 해제하면 즉시 중단 및 제거한다. 물방울 요정은 발사하지 않는다.
- 적 없는 시각 검토용: 순찰 방향의 외측으로 최대 150 논리 px 떨어진 보이지 않는 목표점을 정한다. 전장 마스크로 HUD를 가리지 않는다. 기존 SVG의 가시 영역 및 고품질 축소를 재사용한다. 명중, 실제 피해, 무기 강화, 장착 상태 연동, 적 추적·적 충돌은 이번 범위에 포함하지 않는다. 아래 동작·크기·주기는 사용자 미지정 임시 시각 비교값이다.

| 무기 | 시각 동작 |
| --- | --- |
| 물풍선 | 포물선 투척 후 원형 물보라 |
| 부메랑 | 곡선으로 왕복, 이동 중인 나뭇잎 요정에게 복귀 |
| 바퀴 | 회전하며 직진 |
| 화분 | 목표점 위에서 낙하 후 충격 원 |
| 종이비행기 | 곡선 비행 |
| 탱탱볼 | 목표점을 지나 방향을 바꾸며 튀는 모션 |
| 끈끈이 | 투척 후 커지는 바닥 장판 |
| 스프링클러 | 배치 후 원형 물방울 |
| 돌멩이 | 회전하며 직선 투척 |
| 빗자루 | 요정 주변 부채꼴 휘두르기 |

ESC 일시정지 중 발사·애니메이션을 정지하고 셀렉트를 숨긴다. 재개하면 선택을 복원하며 새 게임에서 무기 없음으로 초기화한다. DOM 셀렉트는 씬 종료 시 제거하고 부모 화면 배율을 따른다.

## 검증

- 실제 저장 소스의 모델을 직접 평가하여 10종 선택, 물방울 요정 발사 차단, 나뭇잎 요정 단독 발사, 시간별 유한 좌표 및 선택 해제 등 1,132개 검사 통과. JS 구문 확인.
- `tests/hero-weapon-browser.mjs`: 960×540 및 1280×720 Chromium에서 10종 실제 선택/렌더링, 적 없음, 단독 발사, 일시정지/재개/선택 해제/종료 정리 검증을 CI에 등록한다. 브라우저 실행 결과는 해당 Actions 기록을 확인한다.
