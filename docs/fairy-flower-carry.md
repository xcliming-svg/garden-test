# 나뭇잎 요정 꽃 운반 실험 (feature/fairy-flower-carry)

- 기준 main: 56a1ab7 (V3 캠페인 포함). 실험 브랜치에서만 기본 활성화; lab, 명시적 시뮬레이션, 기존 드래그 회귀 테스트는 제외. main/devel에는 아직 통합하지 않는다.
- WASD/방향키: 나뭇잎 요정 직접 이동. 입력 없으면 정지, 대각선 정규화, 전장 경계 제한. 물방울 요정은 기존 순찰 유지. 기존 무기/적/도안/드롭률/성장 시간 변경 없음. 자동 공격 위치는 실제 요정 중심 좌표를 사용한다.
- Space: 가까운 꽃 카드(28 논리 px) 하나 줍기, 또는 도안의 정확한 종류/인접 빈칸 위에서 심기. 꽃을 들면 아이콘이 요정 위를 따라간다. 꽃 카드 마우스 드래그 제거. Q: 들고 있는 꽃을 기존 카드 배치 규칙에 따라 다시 내려놓기, 남은 카드 수명 유지. 운반 중 만료 정지. 원래 드래그와 동일한 식재/성장/회복 모델 공유. 기존 마우스 꽃 제거는 유지.
- 일반 아이템은 기존 마우스 드래그 장착/교체, 보석/하트의 기존 자동 획득 및 확장 클릭 유지. 수동 이동 시에도 유물 자석의 기존 방향/거리 규칙 사용. 요정 몸은 다른 꽃/적과 충돌하지 않는다. 기존 바퀴 및 설치 무기는 정원 내부에서 기존 제약에 따라 일부 발사 불가할 수 있다.
- 시험 속도 120px/s (기존 40 + 80), 신발 효과 +10 및 기존 상한 80에 +80 적용. HUD는 직접 이동 속도 표시. 보조 요정은 기존 속도. 자동 복귀/순찰 전환, 운반량 확대, 장비 키보드 전환, 드롭/웨이브 재조정은 미구현.
- 검증: 순수 이동/거리 검사, 실제 브라우저 2개 해상도에서 원거리 줍기 거부, 이동·운반·식재, 잘못된 식재 방지, Q 내려놓기, 일반 장비 드래그, 일시정지/재시작 및 기존 자동 플레이 회귀. 검증 결과는 CI에서 확인. 사람 플레이 재미 및 전체 50스테이지 밸런스는 미확정.
