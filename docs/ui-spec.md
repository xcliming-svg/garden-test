# UI 현행 규격 — 메뉴부터 전장까지

> **현재 devel 기준:** 현재 단일 디자인 좌표계와 세부 UI 규격은 [960×540 현행 규격](./resolution-960x540.md)이 우선한다. 아래 640×360 및 1280×720 수치·확정 이력은 과거 main 기준 기록이며 현재 devel에 적용하지 않는다. main 변경이나 게임플레이 구현을 승인하는 문서가 아니다.


- 기준일: 2026-11-12
- 범위: 사용자 승인 UI 및 현재 프로토타입에 적용한 표시·조작 규칙.
- 단위: 별도 표기가 없으면 640×360 기준 논리 px. 메뉴 소스의 1280×720 좌표는 2로 나누어 비교한다.
- 정확한 에셋 좌표와 전체 팔레트: [ASSET_SPECS.md](../ASSET_SPECS.md). 게임 설계·구현 구분: [implementation.md](./implementation.md). 결정 배경: [ui-decisions.md](./ui-decisions.md). 이력: [changes.md](./changes.md).

## 1. 공통 디자인

| 속성 | 확정 규격 |
| --- | --- |
| 화면 | 16:9, 전장 640×360, 메뉴 1280×720 디자인 좌표 |
| 간격 | 2/4/8/12/16, 기본 8. 메뉴의 대응값 4/8/16/24/32 |
| 모서리 | 직각; 라운드·장식 프레임 없음 |
| 기능적 보더·구분선 | 논리 1px, 메뉴 좌표 2px. 호버 시 두께 불변 |
| 폰트 | Fusion Pixel 10px Proportional KO Regular 400, 한글/영문/숫자 공통 |
| 글자 크기 | 기본 10, 팝업 제목 20, 메인 제목 30, 하단 및 카드 정보창 7, 확장 비용 7 또는 6 |
| 렌더링 | 실제 카메라 배율(최소 1)에 래스터화, 텍스트별 NEAREST, 글리프 원본 보존; 비정수 배율 허용 |
| 색상 | Garden 32만 참조, 원본은 src/palette.js |

테두리 방식은 용도에 따라 구분한다. 버튼·팝업·정보창은 Rectangle 중앙 스트로크, 아이템 카드는 내부 1px 프레임, 전장 경계·그리드·게이지는 1px 채움, 하단 슬롯은 테두리 없는 단색 사각형, 정원은 흙색 면과 드래그 중 후보 + 및 선택된 칸의 1px 사각형이다. 서로 다른 역할의 모양을 억지로 동일하게 만들지 않는다. 반투명 오버레이·비활성 강조·안티앨리어싱으로 합성된 화면 픽셀은 32색 원본과 달라질 수 있다. 새 기본색을 추가한 것은 아니다.

## 2. 메뉴·팝업

| 상태 | 배경 | 테두리 | 글자 |
| --- | --- | --- | --- |
| 일반 버튼 | soil | slot | paper |
| 일반 호버 | grid | paper | paper |
| 주요 버튼 / 활성 탭 | grid | paper | paper |
| 위험 버튼 | soil (호버 grid) | red | paper |
| 비활성 | ink | edge | disabled |

주요 행동은 primary, 선택 탭은 selected 속성으로 분리한다. 모두 1px 논리 테두리 유지. 일반 버튼 높이 24, 주요 세로 간격 4; 개발 전용 결과 미리보기 버튼은 높이 20인 예외. 버튼 폭과 팝업 크기는 콘텐츠에 따라 다르다. 메뉴 크기·위치는 기존 배치를 유지한다.

| 화면 | 팝업 크기 또는 버튼 규격(논리) | 강조 |
| --- | --- | --- |
| 메인 메뉴 | 주요 버튼 196×24, 세로 4px 간격 | 제목·주요 버튼 paper |
| 일시정지 | 264×260, 주요 버튼 196×24 | paper, 메인 메뉴로 버튼 red |
| 설정 | 464×272, 탭 136×24 | edge 패널, 활성 탭 paper |
| 도감 | 464×272, 내부 자리 432×152 | edge 패널 |
| 복귀 확인 | 304×160, 버튼 120×24 | red, 질문 문장 10px |
| 성공/실패 | 448×248, 버튼 136×24 | 성공 growth, 실패 red |

설정·도감은 공통 셸, 팝업은 shadow 74% 오버레이를 사용한다. 중첩 오버레이로 화면이 더 어두워지는 현상은 확인 대상이며 이번에는 수정하지 않았다. 메뉴 상하 구분선 alpha 0.8, 설정 행 구분선 alpha 0.6, 기타 구분선 alpha 1은 의도적으로 현재 구현을 유지한다.

## 4. 하단 HUD — 확정

| 영역 | 좌상단 | 크기 |
| --- | --- | --- |
| 왼쪽 능력치 | 8,324 | 126×36 |
| 중앙 슬롯 | 191,330 | 258×24 |
| 오른쪽 능력치 | 506,324 | 126×36 |

좌우는 동일한 42×36px 3열, 화면 바깥쪽부터 배치, 슬롯과 각 57px 간격. 열 중심 x=29/71/113 및 527/569/611, 전체 묶음 중심 y=342. 레이블과 수치 행은 실제 텍스트 크기로 중앙 정렬, 줄 사이 1px, 수치와 증감 2px, 모두 7px. 증감은 수치 바로 오른쪽에 붙이고 행 전체를 중앙 정렬한다. 별도 그룹 제목·꽃 접두어 없음.

- 왼쪽: 방어력 / 최대 체력 / 행운. 꽃 한 송이 기준 방어력·HP, 행운은 도안에 필요한 꽃 등장 확률과 연관.
- 오른쪽: 이동 속도 / 획득 범위 / 초당 피해량. 수호자 이동·획득 및 장착 무기 피해. 수호자 자체 체력은 표시하지 않는다.
- 슬롯 24×24, 간격 2px, 첫 x=191, 마지막 x=425. 초기 일반 4칸, 최대 일반 10칸 설계; 현재 시안은 일반 9+비활성 확장 1.
- 확장 슬롯 6×6 아이콘 자리+비용 999, 항상 비활성 soil 배경/disabled 아이콘·수치, 드래그 중에도 변경하지 않으며 실제 해금은 없음.  아이콘/수치 간격 2px, 좌우 최소 2px, 중앙 정렬. 999는 예시, 실제 비용 미정. 최대 10칸이면 확장 슬롯 제거하는 설계는 미구현.

## 5. 아이템 카드 및 정보창 — 확정

| 요소 | 규격 |
| --- | --- |
| 장착 카드 | 24×24 외형, paper 1px 내부 프레임, grid 채움, 3px 패딩, 16×16 손수레 아이콘 중앙. 전장/장착 동일 |
| 꽃 드롭 | 24×24 외형, growth 1px 내부 프레임, grid 채움, 3px 패딩, 16×16 꽃 아이콘 중앙. 심어진 뒤 프레임 없는 16×16 꽃 |
| 정보창 | 고정 폭 120px(스트로크 포함 외곽 121), 높이 가변 |
| 패딩 / 본문 폭 | 8 / 104px |
| 행 간격 / 줄바꿈 간격 | 4 / 2px |
| 색상 | soil 배경, paper 테두리·제목, edge 구분선, label 설명, disabled 안내 |
| 내용 순서 | 제목 → 구분선 → 설명 → 추가/제거 효과 수치 → 상태 안내 |
| 교체 제목 | 실측 104px 이하 한 줄, 초과 시 기존 이름 뒤 줄바꿈하고 다음 줄 화살표+새 이름. 이름 자체가 길면 추가 줄바꿈 |
| 위치 | 카드 근처 좌우 우선 또는 슬롯 위쪽, 외곽까지 x=8~632, y=32~320 안으로 보정 |

드래그 가능 오브젝트의 종류별 프레임 색상은 고정하고 호버·드래그 활성 상태는 내부 면 edge로 강조한다. 카드/장착 슬롯 호버 또는 클릭에서 한 개의 정보창. 클릭 고정은 다시 클릭/바깥 클릭으로 해제. 아이템 카드를 드래그할 때 빈 슬롯 또는 전장에서는 정보창 숨김, 기존 장착 아이템과 교체하는 유효 슬롯 위에서만 슬롯 기준으로 고정 표시. 드래그 중 일반 슬롯 9칸 단색 면 위에 후보 중앙 growth 7×7px + (두께 1px), 진입 대상만 같은 growth 1px 사각형으로 변경, 확장 슬롯은 항상 비활성 유지, 교체 대상 기존 장착 카드는 미리보기 중 잠시 숨김, 하단은 최종 예상 수치와 순증감(황록/빨강)을 함께 표시한다. 유효 슬롯 진입 시 원래 카드는 커서를 추적하며 알파 0.25, 별도 24px 장착 카드 미리보기(알파 0.45)만 슬롯 중심에 스냅하며, 놓으면 임시 장착·교체(이전 아이템 제거), 무효 위치/확장 슬롯/화면 이탈/일시정지 시 복귀. 새 게임에서 초기화. 실제 게임 아이템 효과·획득·저장 및 확장 로직은 없다.

## 6. 검증 및 미확정

이전 UI 및 카드 작업에서 JS 5개 구문, 해상도/씬 모의 검사, 능력치 중앙 정렬 78건, 정보창 경계 108개 조합, 교체 제목 625개 모의 폭 조합, 메뉴/팝업/결과 7종·버튼 23·패널 7·구분선 14·설정 탭 전환 3건을 검증했다. 실제 브라우저 자동 실행/픽셀 단위 시각 검증, 실제 게임 데이터 및 에셋의 검증은 미실행이다.

추후 수치 정책: HUD 예약 초과 시 축약 정책, 42px 능력치 열의 장기 최대 수치, 매우 긴 설명/제목의 정보창 최대 높이, 실제 확장 비용·행운 확률·DPS 공식·효과 단위는 미정. 7px/6px 비네이티브 글꼴 및 비정수 배율의 실제 가독성, 중첩 오버레이는 확인 대상. 이 목록은 추가 개발 승인이나 게임플레이 구현 계획이 아니다.

### 정원 및 슬롯 공통 상태 UI (2026-11-12)

- 하단 슬롯 24×24, 간격 2px, 테두리 없는 단색 면. 일반 grid(#343D30), 비활성 soil(#222820), 평상시 장착 카드 호버는 내부 edge, 드래그 중 후보와 선택 모두 growth. 정원은 10×10 내부 좌표만 유지하며 전체 그리드/외곽을 숨긴다. 점유 칸의 흙은 bark(#7C4C24) 알파 0.30, 16×16 흙 면으로 표시. 중앙 2×2 시작, 상하좌우 인접 빈칸(초기 8칸) 후보도 평상시 같은 크기·색·알파로 표시. 17px 격자 간격 내 오른쪽·아래 1px 공백, 별도 내부·외부 테두리 없음. 10×10 전체는 동일한 논리 격자를 사용하며 미사용 칸은 투명. 드래그 중 후보 중앙 growth 7×7px + (두께 1px), 후보 외곽선 없음. 진입한 대상만 동일 growth 1px 사각형(16px 면 주변 공백, 외형 18×18)으로 바꾼 후 중심에 별도 16px 꽃 미리보기(알파 0.45)를 스냅. 드래그 카드는 커서를 계속 추적하며 유효 영역에서 알파 0.25. 이탈하면 + 복원 및 카드 알파 1, 미리보기 숨김, 무효 위치 표시 없음. 배치 성공 시 흙 면 연결, 실패·일시정지·화면 이탈 시 복귀.
- 테스트 전용 이미지: 데이지·튤립·해바라기·수국 각 1송이, 적은 모두 달팽이, 아이템 카드 및 장착 아이콘은 모두 손수레. `src/test-sprites.js`의 임시 픽셀 샘플. 데이지/손수레는 제공 SVG, 다른 꽃 3종은 제공 이미지 시트에서 변환. 꽃과 손수레 모두 16px 텍스처, 알파 0/255. 꽃 12px 축소 샘플은 비교용으로 보존. 손수레는 이전 20px 샘플에서 면적 우세색으로 축소, 달팽이 12px는 기존 샘플. 실제 종류/효과 및 최종 아트와 무관. 기존 카드별 임시 효과 데이터 유지. 화면에 '테스트 이미지' 표시. 보석/수호자는 기존 도형 유지.
- 설계 확정: 상하좌우 인접 확장 및 점유 정원을 감싸는 축 정렬 사각형 순찰. 후보 1칸 바깥에 수호자 중심이 위치하도록 점유 외곽에서 중심 기준 2칸 간격을 둔다. 배치 완료 후 경계가 바뀌면 새 경로에 부드럽게 합류한다. 순찰은 화면 테스트 애니메이션(48px/s), 도안 완성도 계산·재화 소비·실제 해금·전투 이동은 미구현.

### 상태색 및 표시 최종 확정
